# TODOS OS TEMAS DE ESTATÍSTICA INFERENCIAL

Aqui está a lista **completa e exaustiva** da Estatística Inferencial, do nível básico ao avançado. Organizei por blocos para não esquecer nada — e no final faço a **ponte** com a Probabilidade que listamos antes.

---

## 🔹 BLOCO 1 — FUNDAMENTOS DA INFERÊNCIA

1. **Introdução à Estatística Inferencial**
   - Definição e objetivo
   - População vs Amostra
   - Parâmetro vs Estatística (estimador)
   - Inferência vs Estatística Descritiva
   - Papel da probabilidade na inferência

2. **Amostragem**
   - Amostragem aleatória simples (AAS)
   - Amostragem estratificada
   - Amostragem por conglomerados
   - Amostragem sistemática
   - Amostragem por conveniência (não-probabilística)
   - Erro amostral vs erro não-amostral
   - Tamanho da amostra

3. **Distribuições Amostrais**
   - Distribuição amostral da média
   - Distribuição amostral da proporção
   - Distribuição amostral da variância
   - Distribuição amostral da diferença de médias
   - Erro padrão (standard error)
   - Teorema Central do Limite aplicado

4. **Teoria da Estimação**
   - Estimador vs estimativa
   - Propriedades dos estimadores:
     - Não-viesamento (unbiasedness)
     - Consistência
     - Eficiência
     - Suficiência
     - Robustez
   - Erro quadrático médio (MSE)
   - Viés vs variância (trade-off)

## 🔹 BLOCO 3 — ESTIMAÇÃO INTERVALAR

   - Nível de confiança (1 − α)

   - Fatores que afetam a largura do IC

9. **IC para Média**

   - IC para μ com σ desconhecido (t de Student)
   - IC para μ com amostras grandes
   - IC para μ em populações finitas

10. **IC para Proporção**
    - IC para p (amostras grandes)
    - IC para p (amostras pequenas — Wilson, Clopper-Pearson)
    - Correção de continuidade

11. **IC para Variância e Desvio Padrão**
    - IC para σ² usando Chi-quadrado
    - IC para σ

12. **IC para Diferença de Médias**
    - Amostras independentes (variâncias conhecidas)
    - Amostras independentes (variâncias desconhecidas — pooled e não-pooled)
    - Amostras pareadas

13. **IC para Diferença de Proporções**
    - Amostras grandes
    - Amostras pequenas

14. **IC para Razão de Variâncias**
    - Distribuição F de Fisher-Snedecor

15. **IC Bootstrap**
    - Bootstrap percentil
    - Bootstrap BCa
    - Bootstrap para estatísticas complexas

16. **IC Bayesianos**
    - Intervalo de credibilidade
    - Prior e posterior
    - HPD (Highest Posterior Density)

## 🔹 BLOCO 4 — TESTES DE HIPÓTESE

    - Erro Tipo I (α) e Erro Tipo II (β)
    - Poder do teste (1 − β)
    - Nível de significância
    - Região crítica e região de aceitação
    - Valor-p (p-value)
    - Teste unilateral vs bilateral
    - Relação entre IC e teste de hipótese

18. **Testes para Média**
    - Teste Z para μ (σ conhecido)
    - Teste t para μ (σ desconhecido)
    - Teste t para amostras pareadas
    - Teste para amostras grandes

19. **Testes para Proporção**
    - Teste Z para uma proporção
    - Teste Z para diferença de proporções
    - Teste exato de Fisher
    - Teste binomial exato

20. **Testes para Variância**
    - Teste Chi-quadrado para σ²
    - Teste F para razão de variâncias

21. **Testes para Diferença de Médias**
    - Amostras independentes (variâncias iguais)
    - Amostras independentes (variâncias desiguais — Welch)
    - Amostras pareadas
    - Teste t de Student
    - Teste de Welch

22. **Testes Não-Paramétricos**
    - Teste de Wilcoxon (sinais e postos)
    - Teste de Mann-Whitney (U)
    - Teste de Kruskal-Wallis
    - Teste de Friedman
    - Teste de Kolmogorov-Smirnov
    - Teste de Shapiro-Wilk (normalidade)
    - Teste de Anderson-Darling
    - Teste de Lilliefors
    - Teste de Runs (aleatoriedade)
    - Teste de McNemar
    - Teste de Cochran
    - Correlação de Spearman
    - Correlação de Kendall (tau)

23. **Testes de Aderência (Goodness-of-Fit)**
    - Teste Chi-quadrado de aderência
    - Teste G (log-likelihood ratio)
    - Teste de Kolmogorov-Smirnov para aderência

24. **Testes de Independência e Associação**
    - Teste Chi-quadrado de independência
    - Teste exato de Fisher (tabelas 2×2)
    - Teste de Mantel-Haenszel
    - Medidas de associação: V de Cramér, Phi, contingência
    - Teste de McNemar (amostras pareadas)

25. **Testes de Homogeneidade**
    - Teste Chi-quadrado de homogeneidade
    - Teste de Levene (homocedasticidade)
    - Teste de Bartlett
    - Teste de Fligner-Killeen

26. **Testes de Aleatoriedade e Ajuste**
    - Teste de Runs

## 🔗 PONTE: PROBABILIDADE → INFERÊNCIA

Aqui está o **mapeamento direto** entre os temas de Probabilidade e os de Inferência. Se algum tema de Probabilidade não tem contrapartida na Inferência, é porque é pré-requisito puro.

| Probabilidade (tema) | Inferência (onde usa) |
|----------------------|----------------------|
| Variáveis Aleatórias | Distribuições amostrais |
| Esperança e Variância | Propriedades dos estimadores (viés, MSE) |
| Distribuições Discretas (Binomial, Poisson) | Testes para proporção, regressão de Poisson |
| Distribuição Normal | IC para média, testes Z e t, TCL |
| Distribuição t de Student | IC e testes para média com σ desconhecido |
| Distribuição Chi-quadrado | IC e testes para variância, testes de aderência e independência |
| Distribuição F | ANOVA, comparação de variâncias |
| Distribuições Conjuntas | Distribuições amostrais conjuntas, regressão |
| Teorema Central do Limite | Base para IC e testes com amostras grandes |
| Lei dos Grandes Números | Consistência de estimadores |
| Convergência em distribuição | Normalidade assintótica, testes assintóticos |
| Cadeias de Markov | MCMC, inferência bayesiana |
| Monte Carlo | Bootstrap, simulação de distribuições amostrais |
| Teoria da Informação | MLE, AIC, BIC, divergência KL |

## ⚠️ OBSERVAÇÕES CRÍTICAS

1. **A Inferência é MUITO maior que a Probabilidade** em número de tópicos. Isso é normal — a Probabilidade é a base; a Inferência é a aplicação.

2. **Se você já tem Probabilidade e Descritiva bem cobertas**, a Inferência precisa de **pelo menos 60–70 tópicos** para ser "nível elevado". Menos que isso é curso introdutório.

3. **Tópicos que quase sempre faltam em cursos brasileiros:**
   - Inferência Causal (tema 75) — cada vez mais essencial
   - Métodos de Reamostragem (tema 66) — Bootstrap e Jackknife
   - Dados Faltantes (tema 71)
   - Meta-Análise (tema 72)
   - Inferência em Amostras Complexas (tema 74)
   - Modelos de Sobrevivência (tema 68)

4. **Se o público é Ciência de Dados**, os blocos 6 (Regressão), 7 (Multivariados), 8 (Séries Temporais) e 9 (Bayesiana) são **obrigatórios**.

5. **Se o público é Engenharia/Confiabilidade**, os blocos 5 (ANOVA), 6 (Regressão) e 10 (Sobrevivência) são essenciais.

6. **Faltou mencionar explicitamente:**
   - **Inferência para processos estocásticos** (além de séries temporais)
   - **Inferência espacial** (geoestatística, kriging)
   - **Inferência funcional** (dados funcionais)
   - **Inferência de alto-dimensional** (p > n, seleção de variáveis)
   - **Inferência distribuída** (federação de dados)

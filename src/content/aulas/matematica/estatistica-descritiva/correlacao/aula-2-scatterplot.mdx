# Diagrama de Dispersão (Scatterplot)

## 1. INTRODUÇÃO

&emsp;&emsp;&emsp;Na aula anterior estudámos o **conceito de correlação** — vimos que ela mede a **força** e a **direção** da relação linear entre duas variáveis. Vimos também que o coeficiente de Pearson (r) quantifica essa relação com um número entre −1 e +1.<br>

&emsp;&emsp;&emsp;Mas há um problema fundamental: **um número não conta a história completa**.<br>

&emsp;&emsp;&emsp;Considera o seguinte problema prático:

> **Quatro conjuntos de dados diferentes, todos com a mesma correlação (r = 0,82) e a mesma reta de regressão:**

| Conjunto | Descrição |
|---------|----------|
| **A** | Relação linear típica |
| **B** | Relação curvilínea (não linear) |
| **C** | Relação linear com um outlier extremo |
| **D** | Relação linear com um ponto de alavanca |

**Vamos calcular as medidas que já conhecemos:**

| Medida | Conjunto A | Conjunto B | Conjunto C | Conjunto D |
|---------|---------|---------|---------|---------|
| **Média de X** | 9 | 9 | 9 | 9 |
| **Média de Y** | 7,5 | 7,5 | 7,5 | 7,5 |
| **Correlação (r)** | 0,82 | 0,82 | 0,82 | 0,82 |
| **Reta de regressão** | y = 0,5x + 3 | y = 0,5x + 3 | y = 0,5x + 3 | y = 0,5x + 3 |

&emsp;&emsp;&emsp;Todas as medidas numéricas são **idênticas**! Se usássemos apenas o coeficiente de correlação, concluiríamos que os quatro conjuntos são **iguais**. Mas isso é **falso**!

- O **Conjunto A** é uma relação linear típica.
- O **Conjunto B** é uma relação **curvilínea** — o r de Pearson **não detecta** esta relação.
- O **Conjunto C** tem um **outlier** que distorce a reta.
- O **Conjunto D** tem um **ponto de alavanca** que puxa a reta para si.

&emsp;&emsp;&emsp;Este é o **Quarteto de Anscombe** — um exemplo clássico que mostra que **as estatísticas numéricas sozinhas podem ser enganadoras**. Precisamos de **visualizar** os dados antes de confiar cegamente nos números.<br>

&emsp;&emsp;&emsp;É precisamente aqui que entra o **diagrama de dispersão (scatterplot)** — a ferramenta visual que revela o que os números escondem.

> **💡 Dica de Ouro:** A visualização **antecede** o cálculo. Nunca calcules uma correlação sem primeiro olhar para o scatterplot. O número pode mentir — o gráfico não.

**📌 Nota sobre dados agrupados:**

O scatterplot é uma ferramenta para **dados brutos** (pares individuais). Para dados agrupados, usamos outras representações (tabelas de contingência, heatmaps).

| Forma | Representação visual |
|---------|----------|
| **Dados brutos** | Scatterplot (cada ponto = um par) |
| **Agrupados por lista** | Heatmap ou bubble chart |
| **Agrupados por intervalo** | Heatmap |

## 2. O QUE É UM DIAGRAMA DE DISPERSÃO?

&emsp;&emsp;&emsp;O **diagrama de dispersão** (ou **scatterplot**) é um gráfico que representa **pares de valores** (xi, yi) como pontos num plano cartesiano. Cada ponto representa uma observação.

**📌 Estrutura:**

| Elemento | Descrição |
|---------|----------|
| **Eixo horizontal (X)** | Variável independente (ou preditora) |
| **Eixo vertical (Y)** | Variável dependente (ou resposta) |
| **Cada ponto** | Um par (xi, yi) |
| **Padrão dos pontos** | Revela a relação entre X e Y |

**📌 O que o scatterplot revela:**

| Padrão | Interpretação |
|---------|----------|
| **Nuvem ascendente** | Correlação positiva |
| **Nuvem descendente** | Correlação negativa |
| **Nuvem sem padrão** | Correlação nula |
| **Curva** | Relação não linear |
| **Pontos isolados** | Outliers |
| **Ponto distante na horizontal** | Ponto de alavanca |
| **Grupos separados** | Subpopulações |

## 3. COMO CONSTRUIR UM SCATTERPLOT

### 3.1 Passo a Passo

| Passo | Descrição |
|---------|----------|
| **1** | Escolher duas variáveis quantitativas (X e Y) |
| **2** | Definir qual é a independente (X) e qual é a dependente (Y) |
| **3** | Desenhar os eixos com escalas adequadas |
| **4** | Plotar cada par (xi, yi) como um ponto |
| **5** | Adicionar título, rótulos e legenda |
| **6** | Analisar o padrão visual |

## 4. O QUE PROCURAR NUM SCATTERPLOT

### 4.1 Direção

| Padrão | Direção |
|---------|----------|
| Nuvem ascendente (↗) | **Positiva** |
| Nuvem descendente (↘) | **Negativa** |
| Nuvem sem padrão (→) | **Nula** |

### 4.2 Força

| Padrão | Força |
|---------|----------|
| Pontos muito próximos de uma reta | **Forte** |
| Pontos moderadamente dispersos | **Moderada** |
| Pontos muito dispersos | **Fraca** |

### 4.3 Forma

| Padrão | Forma |
|---------|----------|
| Pontos alinhados numa reta | **Linear** |
| Pontos formando uma curva | **Não linear** |
| Pontos formando grupos | **Multimodal** |

### 4.4 Outliers

| Padrão | Interpretação |
|---------|----------|
| Ponto isolado longe da nuvem | **Outlier** — pode distorcer o r |
| Ponto distante na horizontal | **Ponto de alavanca** — puxa a reta de regressão |
| Ponto distante na vertical | **Outlier de resposta** — afeta o r, mas não a reta |

## 6. SCATTERPLOT COM DADOS AGRUPADOS

&emsp;&emsp;&emsp;Quando os dados estão agrupados (por lista ou por intervalo), o scatterplot tradicional não funciona — cada ponto representaria uma **frequência**, não uma observação individual. Nesses casos, usamos:

&emsp;&emsp;&emsp;Um **heatmap** representa a **frequência conjunta** de duas variáveis categóricas ou agrupadas. As cores indicam a intensidade da frequência.

**📌 Exemplo:**

| X \ Y | 10 | 20 | 30 |
|---------|---------|---------|---------|
| **5** | 2 | 1 | 0 |
| **10** | 1 | 3 | 1 |
| **15** | 0 | 1 | 2 |

## 7. SCATTERPLOT E CORRELAÇÃO

&emsp;&emsp;&emsp;O scatterplot é a **ferramenta visual** que complementa o **coeficiente de correlação**. Juntos, contam a história completa.

| r | Scatterplot | Interpretação |
|---------|----------|----------|
| r = +1 | Pontos perfeitamente alinhados numa reta ascendente | Correlação positiva perfeita |
| r = +0,8 | Nuvem ascendente, pontos próximos da reta | Correlação positiva forte |
| r = +0,4 | Nuvem ascendente, pontos dispersos | Correlação positiva moderada |
| r = 0 | Nuvem sem padrão | Correlação nula |
| r = −0,4 | Nuvem descendente, pontos dispersos | Correlação negativa moderada |
| r = −0,8 | Nuvem descendente, pontos próximos da reta | Correlação negativa forte |
| r = −1 | Pontos perfeitamente alinhados numa reta descendente | Correlação negativa perfeita |

## 9. VANTAGENS E DESVANTAGENS DO SCATTERPLOT

| Vantagens | Desvantagens |
|---------|----------|
| ✅ **Revela padrões** que os números escondem | ❌ Não quantifica a relação (precisa de r) |
| ✅ **Detecta outliers** visualmente | ❌ Com muitos pontos, pode ficar sobrecarregado |
| ✅ **Detecta relações não lineares** | ❌ Difícil de interpretar com mais de 2 variáveis |
| ✅ **Detecta grupos** (subpopulações) | ❌ Requer escolha adequada de escalas |
| ✅ **Intuitivo** e fácil de entender | ❌ Pode ser enganador se mal construído |
| ✅ **Complementa** o coeficiente de correlação | ❌ Não substitui a análise numérica |

## 10. INTERPRETAÇÃO DO SCATTERPLOT

> **💡 O scatterplot é a ferramenta visual que complementa o coeficiente de correlação**

**📌 Exemplos de interpretação:**

| Contexto | Padrão | Interpretação |
|---------|---------|---------|
| **Horas de estudo vs. notas** | Nuvem ascendente, pontos próximos | Correlação positiva forte |
| **Preço vs. quantidade vendida** | Nuvem descendente, pontos dispersos | Correlação negativa moderada |
| **Altura vs. peso** | Nuvem ascendente, pontos moderadamente dispersos | Correlação positiva moderada |
| **Temperatura vs. consumo de aquecimento** | Nuvem descendente, pontos próximos | Correlação negativa forte |
| **Cor do cabelo vs. inteligência** | Nuvem sem padrão | Correlação nula |

**📌 O que procurar:**

1. **Direção:** ascendente, descendente ou nula?
2. **Força:** pontos próximos ou dispersos?
3. **Forma:** linear ou curvilínea?
4. **Outliers:** há pontos isolados?
5. **Grupos:** há subpopulações?

## 11. QUANDO USAR O SCATTERPLOT

| Critério | Scatterplot |
|---------|----------|
| **Duas variáveis quantitativas** | ✅ Único |
| **Detectar relação linear** | ✅ Único |
| **Detectar relação não linear** | ✅ Único |
| **Detectar outliers** | ✅ Único |
| **Detectar grupos** | ✅ Único |
| **Complementar o r** | ✅ Único |
| **Mais de duas variáveis** | ❌ Usar pairplot ou heatmap |
| **Dados categóricos** | ❌ Usar gráfico de barras ou heatmap |

**Fluxo de Decisão:**

1. Tens **duas variáveis quantitativas**? → **Scatterplot**
2. Queres **detectar a forma** da relação? → **Scatterplot**
3. Queres **detectar outliers**? → **Scatterplot**
4. Queres **quantificar** a relação? → **Coeficiente de correlação** (Pearson ou Spearman)
5. Tens **mais de duas variáveis**? → **Pairplot** ou **heatmap**
6. Tens **variáveis categóricas**? → **Gráfico de barras** ou **heatmap**

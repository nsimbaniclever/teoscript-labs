# Coeficiente de Spearman

## 1. INTRODUÇÃO

&emsp;&emsp;&emsp;Na aula anterior estudámos o **coeficiente de Pearson** — a medida padrão para quantificar a relação **linear** entre duas variáveis quantitativas. Vimos que ele é poderoso, mas tem **limitações sérias**:

- **É sensível a outliers** — um único valor extremo pode distorcer completamente o r.
- **Só detecta relações lineares** — uma relação curvilínea (monótona) pode ter r ≈ 0, mesmo sendo forte.
- **Exige dados quantitativos** — não funciona para dados ordinais (rankings).

&emsp;&emsp;&emsp;Considera o seguinte problema prático:

> **Dois conjuntos de dados com relação monótona, mas um tem um outlier extremo:**

**Conjunto A (sem outlier):**
| X | Y |
|---------|---------|
| 1 | 2 |
| 2 | 4 |
| 3 | 5 |
| 4 | 8 |
| 5 | 9 |

**Conjunto B (com outlier):**
| X | Y |
|---------|---------|
| 1 | 2 |
| 2 | 4 |
| 3 | 5 |
| 4 | 8 |
| 5 | 100 |

**Vamos calcular o coeficiente de Pearson para ambos:**

| Conjunto | r de Pearson |
|---------|---------|
| **A** | ≈ 0,98 (correlação positiva forte) |
| **B** | ≈ 0,75 (correlação positiva moderada) |

&emsp;&emsp;&emsp;Repara: o **outlier** (100) no Conjunto B **reduziu drasticamente** o r de Pearson. Mas a **relação monótona** entre X e Y é a **mesma** nos dois conjuntos — quando X aumenta, Y **sempre** aumenta. O outlier não muda a **ordem** dos dados, mas muda o **valor** do r.<br>

&emsp;&emsp;&emsp;Precisamos de uma medida que:
1. **Seja robusta a outliers** — não seja distorcida por valores extremos.
2. **Detete relações monótonas** — não apenas lineares.
3. **Funcione com dados ordinais** — rankings, escalas de Likert, etc.

&emsp;&emsp;&emsp;É precisamente aqui que entra o **coeficiente de correlação de Spearman** — a alternativa **não paramétrica** ao Pearson.

> **💡 Dica de Ouro:** O coeficiente de Spearman é o **coeficiente de Pearson aplicado aos postos**. Em vez de usar os valores originais, usa a **ordem** dos valores. Isto torna-o **robusto a outliers** e capaz de detetar **relações monótonas**.

**📌 Nota sobre dados agrupados:**

O coeficiente de Spearman pode ser calculado em três formas:

| Forma | O que tens | Exemplo |
|---------|---------|---------|
| **Dados brutos** | Pares de valores individuais | (1,2), (2,4), (3,5)... |
| **Agrupados por lista** | Tabela de frequências dupla | Tabela de contingência |
| **Agrupados por intervalo** | Classes + frequência | Tabela de dupla entrada |

## 2. O QUE É O COEFICIENTE DE SPEARMAN?

&emsp;&emsp;&emsp;O **coeficiente de correlação de Spearman** (ρ, ou rs) é uma medida **não paramétrica** que quantifica a **força** e a **direção** da **relação monótona** entre duas variáveis. Foi desenvolvido por **Charles Spearman** no início do século XX.

**📌 Definição formal:**

$$
\color{blue} \rho = 1 - \frac{6 \sum_{i=1}^{n} d_i^2}{n(n^2 - 1)}
$$

Onde:
- **di** = diferença entre os postos de X e Y para cada par
- **n** = número de pares
- **ρ** = coeficiente de Spearman

**📌 Definição alternativa:**

&emsp;&emsp;&emsp;O coeficiente de Spearman é simplesmente o **coeficiente de Pearson aplicado aos postos** (rankings) em vez dos valores originais.

$$
\color{blue} \rho = r(\text{postos de } X, \text{postos de } Y)
$$

**📌 Propriedades do ρ:**

| Propriedade | Descrição |
|---------|----------|
| **Intervalo** | −1 ≤ ρ ≤ +1 |
| **Adimensional** | Não tem unidade |
| **Simétrico** | ρ(X, Y) = ρ(Y, X) |
| **Robusto a outliers** | Usa postos, não valores |
| **Deteta relações monótonas** | Não precisa ser linear |
| **Apropriado para dados ordinais** | Não exige normalidade |
| **Menos poderoso que Pearson** | Se a relação for linear e sem outliers, Pearson é melhor |

**📌 Interpretação do coeficiente:**

| Valor de ρ | Interpretação |
|---------|----------|
| ρ = +1 | Correlação **positiva perfeita** (monótona) |
| 0,7 ≤ ρ < 1 | Correlação **positiva forte** |
| 0,3 ≤ ρ < 0,7 | Correlação **positiva moderada** |
| 0 < ρ < 0,3 | Correlação **positiva fraca** |
| ρ = 0 | **Ausência de correlação monótona** |
| −0,3 < ρ < 0 | Correlação **negativa fraca** |
| −0,7 < ρ ≤ −0,3 | Correlação **negativa moderada** |
| −1 < ρ ≤ −0,7 | Correlação **negativa forte** |
| ρ = −1 | Correlação **negativa perfeita** (monótona) |

## 3. PASSO A PASSO

### 3.1 Coeficiente de Spearman para Dados Brutos

**📐 Método**

| Passo | Descrição |
|---------|----------|
| **1** | Ordenar os valores de X e atribuir **postos** (1, 2, 3, ...) |
| **2** | Ordenar os valores de Y e atribuir **postos** (1, 2, 3, ...) |
| **3** | Calcular a diferença entre os postos: <code>di = posto_X − posto_Y</code> |
| **4** | Elevar ao quadrado: <code>di²</code> |
| **5** | Somar todos os quadrados: <code>Σ di²</code> |
| **6** | Aplicar a fórmula: <code>ρ = 1 − (6 × Σ di²) / (n(n² − 1))</code> |

> **⚠️ Nota sobre empates:** Quando há empates (valores iguais), atribui-se a **média dos postos** que seriam ocupados. Neste caso, a fórmula simplificada acima não é exata — deve-se usar o coeficiente de Pearson aplicado aos postos.

<center><details>
<summary>**📌 Exemplo Prático 1 — Sem Outliers**</summary>

**Problema:** Calcular o coeficiente de Spearman para os dados:

| X | Y |
|---------|---------|
| 1 | 2 |
| 2 | 4 |
| 3 | 5 |
| 4 | 8 |
| 5 | 9 |

**Passo 1 — Atribuir postos:**

| X | Posto X | Y | Posto Y |
|---------|---------|---------|---------|
| 1 | 1 | 2 | 1 |
| 2 | 2 | 4 | 2 |
| 3 | 3 | 5 | 3 |
| 4 | 4 | 8 | 4 |
| 5 | 5 | 9 | 5 |

**Passo 2 — Calcular diferenças:**

| Posto X | Posto Y | di | di² |
|---------|---------|---------|---------|
| 1 | 1 | 0 | 0 |
| 2 | 2 | 0 | 0 |
| 3 | 3 | 0 | 0 |
| 4 | 4 | 0 | 0 |
| 5 | 5 | 0 | 0 |
| **Total** | | | **0** |

**Passo 3 — Aplicar a fórmula:**

$$
\rho = 1 - \frac{6 \times 0}{5(25 - 1)} = 1 - 0 = \mathbf{1}
$$

✅ O coeficiente de Spearman é **1** — **correlação positiva perfeita**.

> **🔍 Interpretação:** Existe uma **relação monótona positiva perfeita** entre X e Y. Isto significa que, quando X aumenta, Y **sempre** aumenta (não necessariamente de forma linear, mas de forma consistente). O valor ρ = 1 indica que a ordem dos dados é exatamente a mesma nas duas variáveis.

### 3.2 Coeficiente de Spearman para Dados Agrupados por Lista

&emsp;&emsp;&emsp;Quando os dados estão numa **tabela de frequências dupla**, o cálculo do Spearman torna-se mais complexo porque há **empates** (múltiplas observações com o mesmo valor). Neste caso, a fórmula simplificada não é exata — devemos usar o **coeficiente de Pearson aplicado aos postos**.

**📐 Método**

| Passo | Descrição |
|---------|----------|
| **1** | Expandir a tabela para a lista completa de pares (com repetições) |
| **2** | Atribuir postos a X e Y (com média dos postos em caso de empate) |
| **3** | Calcular o coeficiente de Pearson entre os postos |

| **10** | 1 | 3 | 1 | 5 |

**Passo 3 — Calcular o coeficiente de Pearson entre os postos:**

Média dos postos de X = 6
Média dos postos de Y = 6

| Posto X | Posto Y | (x − 6) | (y − 6) | Produto | (x−6)² | (y−6)² |
|---------|---------|---------|---------|---------|---------|---------|

✅ O coeficiente de Spearman é **0,617** — **correlação positiva moderada a forte**.

> **🔍 Interpretação:** Existe uma **relação monótona positiva moderada a forte** entre X e Y. Isto significa que, em geral, quando X aumenta, Y também tende a aumentar. O valor ρ = 0,617 está na zona moderada-alta.

## 4. COMPARAÇÃO ENTRE PEARSON E SPEARMAN

| Aspeto | Pearson | Spearman |
|---------|---------|---------|
| **O que mede** | Relação **linear** | Relação **monótona** |
| **Dados** | Quantitativos | Quantitativos ou ordinais |
| **Robustez a outliers** | ❌ Sensível | ✅ Robusto |
| **Distribuição** | Assume normalidade | Não assume distribuição |
| **Empates** | Não afetam | Requerem ajuste |
| **Poder estatístico** | Maior (se linear) | Menor (mas mais robusto) |
| **Interpretação** | Força da relação linear | Força da relação monótona |

**📌 Quando os dois coincidem:**

- Quando a relação é **linear** e **sem outliers**, Pearson e Spearman dão valores **próximos**.
- Quando a relação é **monótona não linear** ou há **outliers**, Spearman é **mais adequado**.

**📌 Exemplo comparativo:**

| Conjunto | Pearson (r) | Spearman (ρ) |
|---------|---------|---------|
| **A (linear, sem outliers)** | 0,98 | 1,00 |
| **B (linear, com outlier)** | 0,75 | 1,00 |
| **C (monótona não linear)** | 0,85 | 0,95 |
| **D (não monótona)** | 0,20 | 0,10 |

> **🔍 Interpretação:** No Conjunto B, o outlier reduziu o Pearson (0,75) mas não afetou o Spearman (1,00). No Conjunto C, a relação não linear reduziu o Pearson (0,85) mas o Spearman manteve-se alto (0,95). **Spearman é mais robusto e mais adequado para relações monótonas.**

## 6. VANTAGENS E DESVANTAGENS

| Vantagens | Desvantagens |
|---------|----------|
| ✅ **Robusto a outliers** | ❌ **Perde informação** (usa postos em vez de valores) |
| ✅ **Deteta relações monótonas** | ❌ **Menos poderoso** que Pearson se a relação for linear |
| ✅ **Funciona com dados ordinais** | ❌ **Requer ajuste** para empates |
| ✅ **Não assume normalidade** | ❌ **Não indica a inclinação** da relação |
| ✅ **Adimensional** — sem unidade | ❌ **Não implica causalidade** |
| ✅ **Varie entre −1 e +1** — interpretável | ❌ **Empates reduzem a precisão** |

## 7. QUANDO USAR O COEFICIENTE DE SPEARMAN

| Critério | Spearman |
|---------|----------|
| **Dados ordinais** | ✅ Único |
| **Outliers** | ✅ Único |
| **Relação monótona não linear** | ✅ Único |
| **Distribuição não normal** | ✅ Único |
| **Amostras pequenas** | ✅ Único |
| **Relação linear sem outliers** | ❌ Usar Pearson |
| **Dados quantitativos com distribuição normal** | ❌ Usar Pearson |

**Fluxo de Decisão:**

1. Os dados são **ordinais**? → **Spearman**
2. Há **outliers**? → **Spearman**
3. A relação é **monótona não linear**? → **Spearman**
4. A distribuição **não é normal**? → **Spearman**
5. A relação é **linear** e **sem outliers**? → **Pearson**
6. Em dúvida? → Calcula **ambos** e compara!

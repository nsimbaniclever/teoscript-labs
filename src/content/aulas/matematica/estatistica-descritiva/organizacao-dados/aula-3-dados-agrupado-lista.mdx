# Organização dos dados 

&emsp;&emsp;&emsp;Em estatística, o processo de organização dos dados passa por diferentes etapas. Inicialmente, temos os dados brutos, que são valores sem qualquer ordenação. Em seguida, organizam-se esses dados num Rol, colocando-os em ordem crescente ou decrescente. No entanto, quando o conjunto de dados é extenso, o Rol torna-se longo e pouco funcional. Nesse momento, recorre-se aos dados agrupados, que sintetizam a informação em intervalos de classe, acompanhados das respetivas frequências.

## II. Dados Agrupados

&emsp;&emsp;&emsp;Os dados agrupados podem ser organizados de duas formas distintas, conforme a natureza da variável em estudo: agrupamento por lista (ou por valores discretos) e agrupamento por intervalo (ou por classes).

## 1. Dados Agrupados por Lista

&emsp;&emsp;&emsp;**Agrupar dados por lista** é o processo de pegar um monte de dados brutos espalhados — letras ou números soltos, identificar quais são os valores ou categorias únicos e contar quantas vezes cada um se repetiu. Imagine um saco cheio de feijões de cores diferentes. Agrupar por lista é separar os feijões por cor e contar quantos feijões de cada cor existem no saco. Não é uma análise profunda — é apenas uma **contagem organizada**.

### 1.2 Agrupamento por Lista com Variáveis Qualitativas

&emsp;&emsp;&emsp;Aqui estamos contando **palavras ou categorias**. O processo é o mesmo para nominal e ordinal, mas a **ordem de apresentação** muda.

**1.2.1 🏷️ Nominal (Sem ordem natural)**

&emsp;&emsp;&emsp;Quando estamos perante variáveis qualitativas nominais (por exemplo, cores, marcas ou estados civis), não existe uma 'ordem crescente' a aplicar, uma vez que estas categorias não têm uma sequência lógica. Assim, em vez do Rol, utiliza-se a Tabela de Frequência Simples, ou seja, uma contagem de quantas vezes cada categoria aparece.

#### 1.2.2 📊 Ordinal (Com ordem lógica/hierárquica)

&emsp;&emsp;&emsp;Variáveis ordinais, como escolaridade ou satisfação, têm uma ordem natural. Nesse caso, podemos fazer um Rol segundo essa hierarquia, listando manualmente as categorias do 'pior' para o 'melhor' (ou ao contrário).

/Exemplo: Nível de satisfação (Ruim, Regular, Bom, Ótimo), escolaridade.

<details>
<summary>📝 Exemplo na Mão</summary>

Dados brutos: `Bom, Ruim, Ótimo, Regular, Bom, Ruim, Ótimo, Bom, Regular, Regular`

**Hierarquia: Ruim < Regular < Bom < Ótimo**
- Ruim: II = 2
- Regular: III = 3
- Bom: III = 3
- Ótimo: II = 2

| Ruim | 2 |

### 1.3. Agrupamento por Lista com  Variáveis Quantitativas

&emsp;&emsp;&emsp;Quando as variáveis são quantitativas, ou seja, representam quantidades numéricas, o Rol consiste simplesmente em colocar os valores em ordem crescente ou decrescente. Isto funciona tanto para variáveis discretas (ex.: número de irmãos: 0, 1, 2, 3…) como para variáveis contínuas (ex.: alturas: 1,55 m, 1,60 m, 1,68 m…). É o método mais direto de organizar dados numéricos antes de os agrupar em intervalos.

#### 1.3.1 🔢 Discreta (Números inteiros, contagens)

&emsp;&emsp;&emsp;Variáveis quantitativas discretas são aquelas que só podem assumir valores específicos, normalmente números inteiros, como o número de filhos, o número de irmãos ou o número de faltas. Aqui, o Rol consiste em colocar esses valores em ordem crescente ou decrescente, tornando a análise muito mais simples.

### 3.2 📏 Contínua (Números decimais, medições)

&emsp;&emsp;&emsp;Nas variáveis quantitativas contínuas, os dados podem assumir qualquer valor dentro de um intervalo real, resultando geralmente de medições. O Rol é construído ordenando esses valores de forma crescente ou decrescente, o que permite visualizar a distribuição, identificar os valores mínimo e máximo e preparar os dados para posterior agrupamento em classes
<details>
<summary>📝 Exemplo na Mão</summary>

Dados brutos: 1,58; 1,62; 1,70; 1,58; 1,75; 1,62; 1,80; 1,58; 1,62 <br>
Números únicos:** 1,58; 1,62; 1,70; 1,75; 1,80

**Contagem:**
- 1,58: aparece 3 vezes
- 1,62: aparece 3 vezes
- 1,70: aparece 1 vez
- 1,75: aparece 1 vez
- 1,80: aparece 1 vez

**📊 A Tabela Resultante**

|--------|--------------------------|
| 1,58 | 3 |
| 1,62 | 3 |
| 1,70 | 1 |
| 1,75 | 1 |
| 1,80 | 1 |
| **Total** | **9** |
</details>

## 📝 Resumo — Quadro Comparativo

A tabela abaixo resume as diferentes abordagens para agrupar dados por lista, dependendo do tipo de variável.

| Tipo de Variável | O que contamos | Exemplo | Ordem na lista | Limitação |
|------------------|----------------|---------|----------------|-----------|
| **Qualitativa Nominal** | Categorias sem ordem | Cor dos olhos | Alfabética (opcional) | Nenhuma — contagem simples |
| **Qualitativa Ordinal** | Categorias com hierarquia | Satisfação (Ruim → Ótimo) | Hierárquica (Ruim < Bom) | Nenhuma — contagem simples |
| **Quantitativa Discreta** | Números inteiros | Número de filhos | Crescente (0, 1, 2, 3...) | Nenhuma — contagem simples |
| **Quantitativa Contínua** | Números decimais | Altura (1,58; 1,62...) | Crescente (1,58; 1,62...) | ⚠️ Contagem exata é inútil com muitos dados |

> **📌 Conclusão:** Agrupar por lista é o **primeiro passo** para entender dados. Contar quantas vezes cada valor se repete transforma o caos em informação imediata. Para dados contínuos com muitas variações, este método mostra sua limitação — e é aí que entram os **Intervalos de Classe**, tema da próxima aula.

**Enunciado:** Por que "contar repetições" é o primeiro passo para entender um conjunto de dados?

<details>
<summary>💡 Ver resposta</summary>

**Resposta:**

Contar repetições é o primeiro passo porque:

1. **Transforma o caos em ordem** — dados brutos são difíceis de interpretar, a contagem organizada revela padrões.
2. **Revela a frequência** — sabemos quais valores são mais comuns e quais são raros.
3. **Prepara para análises mais profundas** — a tabela de frequências é a base para gráficos, médias, desvios e outras análises.
4. **É simples e universal** — o conceito de "contar quantas vezes algo aparece" é intuitivo para qualquer pessoa.

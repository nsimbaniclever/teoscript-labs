# COMBINAÇÃO LINEAR

## 1. Definição Formal

### 1.1 Combinação Linear

Sejam $\vec{v}_1, \vec{v}_2, \ldots, \vec{v}_k \in \mathbb{R}^n$ vetores e $c_1, c_2, \ldots, c_k \in \mathbb{R}$ escalares.

Uma **combinação linear** desses vetores é o vetor:

$$
\vec{w} = c_1 \vec{v}_1 + c_2 \vec{v}_2 + \cdots + c_k \vec{v}_k = \sum_{i=1}^{k} c_i \vec{v}_i
$$

**Observações:**
- Os escalares $c_i$ são chamados de **coeficientes** da combinação linear.
- O resultado $\vec{w}$ é um vetor em $\mathbb{R}^n$.
- A combinação linear é uma **operação fechada** no espaço vetorial.

### 1.2 Exemplo 

Dados:

$$
\vec{v}_1 = (1, 2), \quad \vec{v}_2 = (3, 4)
$$

Coeficientes: $c_1 = 2$, $c_2 = -1$

Combinação linear:

$$
\vec{w} = 2(1, 2) + (-1)(3, 4) = (2, 4) + (-3, -4) = (-1, 0)
$$

**Interpretação:** O vetor $(-1, 0)$ é uma combinação linear de $\vec{v}_1$ e $\vec{v}_2$.

## 2. Conjunto Gerador (Span)

### 2.1 Definição

O **conjunto gerado** (ou *span*) por um conjunto de vetores $\{\vec{v}_1, \vec{v}_2, \ldots, \vec{v}_k\}$ é o conjunto de **todas as combinações lineares** possíveis:

$$
\text{span}\{\vec{v}_1, \vec{v}_2, \ldots, \vec{v}_k\} = \left\{ \sum_{i=1}^{k} c_i \vec{v}_i \mid c_i \in \mathbb{R} \right\}
$$

**Interpretação:** É o menor subespaço vetorial que contém todos os vetores $\vec{v}_i$.

### 2.2 Exemplo

$\vec{v}_1 = (1, 0)$, $\vec{v}_2 = (0, 1)$

$$
\text{span}\{(1, 0), (0, 1)\} = \{(c_1, c_2) \mid c_1, c_2 \in \mathbb{R}\} = \mathbb{R}^2
$$

**Interpretação:** Os dois vetores geram todo o plano 2D.

### 2.3 Exemplo

$\vec{v}_1 = (1, 2)$, $\vec{v}_2 = (2, 4)$

$$
\text{span}\{(1, 2), (2, 4)\} = \{c_1(1, 2) + c_2(2, 4)\} = \{(c_1 + 2c_2)(1, 2)\}
$$

**Interpretação:** Apenas uma reta no $\mathbb{R}^2$ é gerada, pois os vetores são dependentes.

## 3. Exemplos Lúdicos para Fixação

### Exemplo 1 – A lanchonete (combinação de ingredientes)

Uma lanchonete tem três ingredientes base:
- Pão: $\vec{p} = (1, 0, 0)$ → (pão, carne, queijo)
- Carne: $\vec{c} = (0, 1, 0)$
- Queijo: $\vec{q} = (0, 0, 1)$

Um cliente pede:
- 2 pães
- 3 carnes
- 1 queijo

**Combinação linear:**

$$
\vec{pedido} = 2\vec{p} + 3\vec{c} + 1\vec{q} = (2, 3, 1)
$$

**Interpretação:** O pedido é uma combinação linear dos ingredientes base.

### Exemplo 2 – O cardápio (combinação de alimentos)

João tem três tipos de refeição:
- Café da manhã: $\vec{c} = (2, 1, 0)$ → (pão, leite, fruta)
- Almoço: $\vec{a} = (0, 3, 2)$
- Jantar: $\vec{j} = (1, 2, 1)$

Se João comer:
- 1 café da manhã
- 2 almoços
- 0 jantares

**Combinação linear:**

$$
\vec{total} = 1\vec{c} + 2\vec{a} + 0\vec{j} = (2, 1, 0) + (0, 6, 4) = (2, 7, 4)
$$

**Interpretação:** Ele consumiu 2 pães, 7 leites e 4 frutas.

### Exemplo 3 – As cores (combinação de cores primárias)

No modelo RGB, qualquer cor é uma combinação linear de:
- Vermelho: $\vec{r} = (1, 0, 0)$
- Verde: $\vec{g} = (0, 1, 0)$
- Azul: $\vec{b} = (0, 0, 1)$

Uma cor roxa (mistura de vermelho e azul):

$$
\vec{roxo} = 0.8\vec{r} + 0\vec{g} + 0.6\vec{b} = (0.8, 0, 0.6)
$$

**Interpretação:** 80% de vermelho e 60% de azul → roxo.

### Exemplo 4 – As notas (combinação de matérias)

João tem notas:
- Matemática: 8.5
- Português: 7.0
- História: 9.2

Se ele quiser calcular uma **média simples**:

$$
\vec{notas} = (8.5, 7.0, 9.2)
$$

$$
\text{média} = \frac{1}{3}\vec{notas} \cdot (1, 1, 1) = \frac{1}{3}(8.5 + 7.0 + 9.2) = 8.23
$$

Isso é uma combinação linear com coeficientes $c_1 = c_2 = c_3 = 1/3$.

## 4. Propriedades da Combinação Linear

| Propriedade | Descrição |
|-------------|-----------|
| **Fechamento** | A combinação linear de vetores em $\mathbb{R}^n$ pertence a $\mathbb{R}^n$ |
| **Associatividade** | A ordem de agrupamento não altera o resultado |
| **Comutatividade** | A ordem dos vetores não altera o resultado |
| **Distributividade** | Coeficientes podem ser somados: $(c+d)\vec{v} = c\vec{v} + d\vec{v}$ |
| **Elemento Neutro** | $0 \cdot \vec{v} = \vec{0}$ |

## 5. Interpretação Geométrica

### 5.1 Um Vetor (Reta)

$$
\text{span}\{\vec{v}\} = \{c\vec{v} \mid c \in \mathbb{R}\}
$$

Geometricamente: uma **reta** que passa pela origem.

### 5.2 Dois Vetores Independentes (Plano)

$$
\text{span}\{\vec{v}_1, \vec{v}_2\} = \{c_1\vec{v}_1 + c_2\vec{v}_2 \mid c_1, c_2 \in \mathbb{R}\}
$$

Geometricamente: um **plano** que passa pela origem.

### 5.3 Três Vetores Independentes (Espaço 3D)

$$
\text{span}\{\vec{v}_1, \vec{v}_2, \vec{v}_3\} = \mathbb{R}^3
$$

Geometricamente: **todo o espaço 3D**.

## 6. Aplicação Direta na Tese

### 6.1 Regressão Linear (Modelo Fundamental)

O modelo de regressão linear é uma combinação linear das características:

$$
y = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b
$$

**Em notação vetorial:**

$$
y = \vec{w} \cdot \vec{x} + b
$$

**Interpretação:** A previsão $y$ é uma combinação linear das características $\vec{x}$.

### 6.2 Redes Neurais (Camadas Densas)

Cada neurônio em uma camada densa calcula:

$$
z = \vec{w} \cdot \vec{x} + b
$$

**Interpretação:** Cada neurônio é uma combinação linear da entrada $\vec{x}$, seguida por uma função de ativação.

### 6.3 PCA (Análise de Componentes Principais)

Cada componente principal é uma combinação linear das características originais:

$$
PC_1 = c_1 x_1 + c_2 x_2 + \cdots + c_n x_n
$$

**Interpretação:** O PCA encontra combinações lineares que maximizam a variância dos dados.

### 6.4 Federação de Aprendizado (FedAvg)

O modelo global é uma combinação linear dos modelos locais:

$$
\vec{w}_{global} = \frac{1}{N} \sum_{i=1}^{N} \vec{w}_i
$$

**Interpretação:** O FedAvg é uma combinação linear com coeficientes $c_i = 1/N$.

### 6.5 Embeddings (Combinações Semânticas)

Em sistemas de recomendação ou NLP:

$$
\vec{rei} - \vec{homem} + \vec{mulher} \approx \vec{rainha}
$$

**Interpretação:** Isso é uma combinação linear de embeddings que captura relações semânticas.

### 6.6 Representação de Dados

Qualquer exemplo em um dataset é uma combinação linear das características:

$$
\vec{cliente} = (idade, renda, compras, tempo)
$$

**Interpretação:** Cada cliente é um vetor que pode ser visto como combinação linear das características base.

### 6.7 Interpolação de Modelos

Em algumas técnicas de otimização, o novo modelo é uma **combinação convexa** (coeficientes não negativos somando 1) de modelos anteriores:

$$
\vec{w}_{novo} = \alpha \vec{w}_1 + (1-\alpha) \vec{w}_2
$$

**Interpretação:** Isso permite suavizar a atualização dos pesos.

## 7. Resumo Estruturado

| Conceito | Definição | Fórmula |
|----------|-----------|---------|
| **Combinação Linear** | Soma de vetores multiplicados por escalares | $\vec{w} = \sum c_i \vec{v}_i$ |
| **Coeficientes** | Escalares que multiplicam os vetores | $c_i \in \mathbb{R}$ |
| **Conjunto Gerador (Span)** | Todas as combinações lineares possíveis | $\text{span}\{\vec{v}_1, \ldots, \vec{v}_k\}$ |
| **Interpretação Geométrica** | Reta, plano ou espaço gerado | Depende da independência linear |

**Enunciado:** Dados $\vec{v}_1 = (1, 3)$ e $\vec{v}_2 = (2, -1)$, calcule a combinação linear:

a) $2\vec{v}_1 + 3\vec{v}_2$  
b) $-1\vec{v}_1 + 4\vec{v}_2$  
c) $0\vec{v}_1 + 5\vec{v}_2$

<details>
<summary>💡 Ver resposta</summary>

**Resposta:**

a) $2(1,3) + 3(2,-1) = (2,6) + (6,-3) = (8,3)$

b) $-1(1,3) + 4(2,-1) = (-1,-3) + (8,-4) = (7,-7)$

c) $0(1,3) + 5(2,-1) = (0,0) + (10,-5) = (10,-5)$

<summary>📗 Exercício 2 (Verificação de Combinação Linear)</summary>

**Enunciado:** Verifique se o vetor $\vec{w} = (5, 7)$ pode ser escrito como combinação linear de:

$$
\vec{v}_1 = (1, 2), \quad \vec{v}_2 = (2, 3)
$$

Dica: Encontre $c_1, c_2$ tais que $c_1(1,2) + c_2(2,3) = (5,7)$.

<details>
<summary>💡 Ver resposta</summary>

**Resposta:**

Sistema:

$$
c_1 + 2c_2 = 5
$$

$$
2c_1 + 3c_2 = 7
$$

Da primeira: $c_1 = 5 - 2c_2$

Substituindo na segunda:

$2(5 - 2c_2) + 3c_2 = 7$

$10 - 4c_2 + 3c_2 = 7$

$-c_2 = -3$

$c_2 = 3$

$c_1 = 5 - 2(3) = 5 - 6 = -1$

**Sim!** $\vec{w} = -1(1,2) + 3(2,3) = (-1,-2) + (6,9) = (5,7)$

</details>

<summary>📗 Exercício 8 (Desafio – Span)</summary>

**Enunciado:** Determine se o vetor $\vec{w} = (1, 2, 3)$ pertence ao span de:

$$
\vec{v}_1 = (1, 0, 1), \quad \vec{v}_2 = (0, 1, 1)
$$

Dica: Encontre $c_1, c_2$ tais que $c_1(1,0,1) + c_2(0,1,1) = (1,2,3)$.

<details>
<summary>💡 Ver resposta</summary>

**Resposta:**

Sistema:

$$
c_1(1,0,1) + c_2(0,1,1) = (1,2,3)
$$

$$
(c_1, c_2, c_1 + c_2) = (1,2,3)
$$

Da primeira: $c_1 = 1$

Da segunda: $c_2 = 2$

Verificando terceira: $c_1 + c_2 = 1 + 2 = 3$ ✓

**Sim!** $\vec{w} = 1(1,0,1) + 2(0,1,1) = (1,2,3)$

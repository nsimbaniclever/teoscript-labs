# AUTOVALORES E CONVERGÊNCIA

## 1. Definição Formal

### 1.1 Sistemas Dinâmicos Discretos

Um **sistema dinâmico discreto** é descrito por:

$$
\vec{x}_{t+1} = A \vec{x}_t
$$

Onde:
- $\vec{x}_t$ é o estado do sistema no tempo $t$.
- $A$ é a matriz de transição.

**Solução geral:**
$$
\vec{x}_t = A^t \vec{x}_0
$$

**Interpretação:** A evolução do sistema é determinada pelas potências de $A$.

### 1.2 Convergência de Sistemas Dinâmicos

A convergência do sistema $\vec{x}_{t+1} = A \vec{x}_t$ é determinada pelos **autovalores** de $A$:

| Condição | Comportamento |
|----------|---------------|
| $|\lambda_i| < 1$ para todos | O sistema **converge** para $\vec{0}$ |
| $|\lambda_i| = 1$ para algum | O sistema **não converge** (oscila ou se mantém) |
| $|\lambda_i| > 1$ para algum | O sistema **diverge** |

**Taxa de convergência:** Determinada pelo **maior autovalor** em módulo (raio espectral):

$$
\rho(A) = \max_i |\lambda_i|
$$

Quanto menor $\rho(A)$, mais rápida a convergência.

## 2. Exemplos Acadêmicos Passo a Passo

### 2.1 Exemplo 1: Sistema Convergente

Seja:
$$
A = \begin{bmatrix} 0.5 & 0 \\ 0 & 0.8 \end{bmatrix}
$$

**Autovalores:** $\lambda_1 = 0.5, \lambda_2 = 0.8$

**Raio espectral:** $\rho(A) = 0.8$

**Comportamento:** Como $|\lambda_i| < 1$, o sistema converge para zero.

**Velocidade:** O termo $0.8^t$ é o que decai mais lentamente.

### 2.2 Exemplo 2: Sistema Divergente

Seja:
$$
A = \begin{bmatrix} 1.2 & 0 \\ 0 & 0.8 \end{bmatrix}
$$

**Autovalores:** $\lambda_1 = 1.2, \lambda_2 = 0.8$

**Raio espectral:** $\rho(A) = 1.2$

**Comportamento:** Como $|\lambda_1| > 1$, o sistema diverge.

### 2.3 Exemplo 3: Sistema com Autovalor Unitário

Seja:
$$
A = \begin{bmatrix} 1 & 0 \\ 0 & 0.8 \end{bmatrix}
$$

**Autovalores:** $\lambda_1 = 1, \lambda_2 = 0.8$

**Comportamento:** O sistema não converge para zero (o componente na direção do autovalor $1$ permanece constante).

## 3. Número de Condição e Convergência

### 3.1 Definição

O **número de condição** de uma matriz $A$ é:

$$
\kappa(A) = \frac{|\lambda_{max}|}{|\lambda_{min}|}
$$

**Interpretação:**
- $\kappa \approx 1$: matriz bem condicionada (convergência rápida).
- $\kappa \gg 1$: matriz mal condicionada (convergência lenta).

### 3.2 Exemplo

Seja:
$$
A = \begin{bmatrix} 0.9 & 0 \\ 0 & 0.1 \end{bmatrix}
$$

**Autovalores:** $\lambda_1 = 0.9, \lambda_2 = 0.1$

**Número de condição:** $\kappa = \frac{0.9}{0.1} = 9$

**Interpretação:** A convergência é dominada pelo autovalor $0.9$, que decai lentamente.

## 4. Exemplos Lúdicos Aprimorados

### 🍔 EXEMPLO 1 – A LANCHONETE (CRESCIMENTO DE ESTOQUE)

A lanchonete tem a matriz de evolução:
$$
A = \begin{bmatrix} 1.2 & 0 \\ 0 & 0.9 \end{bmatrix}
$$

**Autovalores:** $\lambda_1 = 1.2, \lambda_2 = 0.9$

**Interpretação:**
- O estoque de pão cresce 20% a cada dia (diverge).
- O estoque de carne diminui 10% a cada dia (converge para zero).

**A longo prazo:** O sistema diverge (o pão cresce indefinidamente).

### 🧃 EXEMPLO 2 – A CANTINA (DECAIMENTO DE NUTRIENTES)

A cantina tem a matriz de evolução:
$$
A = \begin{bmatrix} 0.9 & 0 \\ 0 & 0.95 \end{bmatrix}
$$

**Autovalores:** $\lambda_1 = 0.9, \lambda_2 = 0.95$

**Interpretação:**
- O açúcar diminui 10% a cada dia.
- O cálcio diminui 5% a cada dia.

**Taxa de convergência:** O cálcio (0.95) é o que decai mais lentamente.

### 📚 EXEMPLO 3 – A BIBLIOTECA (CONVERGÊNCIA DE ESTUDO)

A biblioteca tem a matriz de evolução:
$$
A = \begin{bmatrix} 0.8 & 0.2 \\ 0.2 & 0.8 \end{bmatrix}
$$

**Autovalores:** $\lambda_1 = 1, \lambda_2 = 0.6$

**Interpretação:**
- $\lambda_1 = 1$: O sistema não converge para zero (há um estado estacionário).
- $\lambda_2 = 0.6$: As perturbações decaem com taxa 0.6.

## 5. Aplicação na Tese: Análise de Convergência do FedAvg

### 5.1 FedAvg como Sistema Dinâmico

Em FedAvg, a evolução do modelo global pode ser aproximada por:

$$
\vec{w}_{t+1} = (I - \eta H) \vec{w}_t
$$

Onde:
- $\eta$ é a taxa de aprendizado.
- $H$ é a Hessiana (matriz de segundas derivadas).

**Autovalores de $I - \eta H$:**

$$
\lambda_i = 1 - \eta \mu_i
$$

Onde $\mu_i$ são os autovalores da Hessiana.

### 5.2 Condição de Convergência

Para convergência, precisamos:
$$
|1 - \eta \mu_i| < 1 \quad \text{para todos } i
$$

**Condição para o passo $\eta$:**
$$
0 < \eta < \frac{2}{\mu_{max}}
$$

**Número de condição:**
$$
\kappa = \frac{\mu_{max}}{\mu_{min}}
$$

**Interpretação:** Quanto maior $\kappa$, mais lenta é a convergência.

### 5.3 Exemplo Numérico

Suponha que a Hessiana tenha autovalores:
$$
\mu_1 = 10, \mu_2 = 0.1
$$

**Número de condição:** $\kappa = \frac{10}{0.1} = 100$

**Passo máximo:** $\eta < \frac{2}{10} = 0.2$

**Taxa de convergência:** Dominada pelo autovalor $1 - 0.2 \cdot 0.1 = 0.98$, que é muito próximo de 1 → convergência lenta.

## 8. EXERCÍCIO COMPUTACIONAL

<details>
<summary>🐍 Ver código (Python/NumPy)</summary>

```python
import numpy as np
import matplotlib.pyplot as plt

# Simulação de sistema convergente
A = np.array([[0.5, 0], [0, 0.8]])
x0 = np.array([1, 1])

# Evolução
t_max = 20
x_t = np.zeros((t_max, 2))
x_t[0, :] = x0

for t in range(1, t_max):
    x_t[t, :] = A @ x_t[t-1, :]

plt.plot(x_t[:, 0], label='Componente 1')
plt.plot(x_t[:, 1], label='Componente 2')
plt.xlabel('Tempo')
plt.ylabel('Estado')
plt.legend()
plt.grid()
plt.show()

# Raio espectral
autovalores = np.linalg.eigvals(A)
rho = np.max(np.abs(autovalores))
print(f"Raio espectral: {rho}")
```

# Simulação de sistema convergente
A <- matrix(c(0.5, 0, 0, 0.8), nrow=2)
x0 <- c(1, 1)

x_t <- matrix(0, nrow=t_max, ncol=2)

> *A convergência de sistemas dinâmicos é determinada pelos autovalores da matriz de transição. O raio espectral $\rho(A)$ controla a taxa de convergência: $\rho(A) < 1$ → convergência; $\rho(A) > 1$ → divergência. Em FL, a análise de convergência do FedAvg envolve os autovalores da Hessiana e o número de condição.*

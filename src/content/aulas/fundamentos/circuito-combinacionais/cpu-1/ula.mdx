# Unidade Lógica e Aritmética

## 1. Introdução

Até agora, percorremos um longo caminho. Começamos com os fundamentos — o bit, o byte, os sistemas numéricos. Construímos a lógica com portas AND, OR, NOT. Aprendemos a somar e subtrair com circuitos combinacionais. Exploramos a memória com flip-flops, registradores e contadores. E finalmente, vimos como os barramentos conectam tudo em uma grande rede digital.<br><br>

Mas há um lugar onde tudo isso se encontra — um componente que é, talvez, o mais importante de todo o computador. Um lugar onde os dados entram, as operações acontecem, e os resultados saem. Um lugar que é o **coração pulsante** da CPU. <br><br>

Esse lugar é a **ULA** — a **Unidade Lógica e Aritmética**.<br><br>

A ULA é o componente responsável por realizar **todas as operações matemáticas e lógicas** do computador. É ela que soma, subtrai, compara, faz AND, OR, XOR, e muito mais. Cada vez que você abre uma planilha, joga um jogo, ou assiste a um vídeo, a ULA está trabalhando incansavelmente, realizando bilhões de operações por segundo.<br><br>

Nesta aula, vamos explorar a ULA em detalhes: como ela é construída, como funciona, quais operações ela realiza, e como ela se encaixa no resto da CPU. Vamos entender por que ela é chamada de "coração computacional" do processador.<br><br>


## 2. O Que é a ULA?

### 2.1 Definição

A **ULA** (Unidade Lógica e Aritmética), ou **ALU** (*Arithmetic Logic Unit*) em inglês, é o circuito combinacional da CPU responsável por executar operações aritméticas e lógicas sobre os dados.

### 2.2 Funções da ULA

| Tipo | Operações | Exemplos |
|------|-----------|----------|
| **Aritméticas** | Soma, subtração, incremento, decremento | A + B, A - B, A + 1, A - 1 |
| **Lógicas** | AND, OR, NOT, XOR, NAND, NOR | A AND B, A OR B, NOT A |
| **Comparações** | Igualdade, maior que, menor que | A = B, A > B, A < B |
| **Deslocamentos** | Shift left, shift right | A << 1, A >> 1 |

### 2.3 Analogia

Pense na ULA como uma **calculadora industrial** dentro da CPU:

- Você coloca dois números (os operandos).
- Você seleciona a operação (soma, subtração, AND, etc.).
- A calculadora executa e devolve o resultado.
- Tudo isso em frações de nanossegundo.

## 3. Estrutura Interna da ULA

### 3.1 Componentes principais

| Componente | Função |
|------------|--------|
| **Circuitos Aritméticos** | Somador, subtrator, incrementador, decrementador |
| **Circuitos Lógicos** | AND, OR, XOR, NOT, NAND, NOR |
| **Multiplexador (MUX)** | Seleciona qual operação será enviada como resultado |
| **Registradores de entrada** | Armazenam os operandos A e B |
| **Registrador de saída** | Armazena o resultado |
| **Flags (bits de status)** | Indicam condições especiais (overflow, zero, negativo) |

### 3.2 As flags da ULA

As **flags** são bits de status que indicam o resultado da última operação:

| Flag | Significado | Quando é 1 |
|------|-------------|------------|
| **Z (Zero)** | O resultado é zero | Resultado = 0 |
| **N (Negative)** | O resultado é negativo | MSB = 1 |
| **C (Carry)** | Houve vai-um | Overflow na soma |
| **V (Overflow)** | Overflow em Complemento de 2 | Resultado não cabe |
| **E (Equal)** | A e B são iguais | A = B |

### 3.3 Exemplo: ULA com 4 operações

| Opcode (S₁,S₀) | Operação | Fórmula |
|----------------|----------|---------|
| 00 | Soma | F = A + B |
| 01 | Subtração | F = A - B |
| 10 | AND | F = A ∧ B |
| 11 | OR | F = A ∨ B |


## 4. Operações Aritméticas

### 4.1 Soma (A + B)

- Usa o **somador completo** que estudamos anteriormente.
- Entradas: A, B, Cin (carry de entrada).
- Saídas: Soma, Cout (carry de saída).

**Exemplo:** 5 + 3 = 8
<pre>
  0101  (5)
+ 0011  (3)
────────
  1000  (8)
</pre>

### 4.2 Subtração (A - B)

- Usa o **subtrator** via Complemento de 2.
- A - B = A + (~B + 1).

**Exemplo:** 5 - 3 = 2
<pre>
  0101  (5)
+ 1101  (-3)
────────
  0010  (2)
</pre>

### 4.3 Incremento (A + 1)

- Soma com Cin = 1 e B = 0.
- Muito usado em contadores e no PC.

### 4.4 Decremento (A - 1)

- Subtrai 1 via Complemento de 2.


## 5. Operações Lógicas

### 5.1 AND, OR, XOR, NOT

| Operação | Expressão | Tabela Verdade (A=1, B=0) |
|----------|-----------|---------------------------|
| **AND** | F = A ∧ B | 1 ∧ 0 = 0 |
| **OR** | F = A ∨ B | 1 ∨ 0 = 1 |
| **XOR** | F = A ⊕ B | 1 ⊕ 0 = 1 |
| **NOT** | F = ¬A | ¬1 = 0 |

### 5.2 Comparações

A ULA também pode comparar valores:

| Operação | Como é feita |
|----------|--------------|
| **A = B** | A - B = 0 → flag Z = 1 |
| **A > B** | A - B > 0 → flag N = 0 |
| **A < B** | A - B < 0 → flag N = 1 |

### 6.2 O ciclo da ULA

1. **Busca:** A UC envia o opcode (código da operação) para a ULA.
2. **Leitura:** A ULA recebe os operandos A e B dos registradores.
3. **Execução:** A ULA realiza a operação especificada pelo opcode.
4. **Escrita:** O resultado é armazenado em um registrador ou na memória.
5. **Flags:** As flags são atualizadas (Z, N, C, V).


## 7. Aplicações Reais

| Aplicação | Como a ULA contribui |
|-----------|---------------------|
| **Planilhas** | Soma, subtração, comparação de células |
| **Jogos** | Cálculos de física, detecção de colisão |
| **Compressão de dados** | Operações lógicas e aritméticas |
| **Criptografia** | XOR, AND, OR em algoritmos de cifra |
| **IA/ML** | Operações matriciais (soma, multiplicação) |
| **Edição de vídeo** | Filtros, transformações, correção de cor |

> **"A ULA é o coração computacional da CPU — o componente que realmente executa as operações que fazem o computador funcionar. Ela combina circuitos aritméticos (soma, subtração) e lógicos (AND, OR, NOT) com um multiplexador que seleciona a operação correta baseada no opcode. As flags (Zero, Negativo, Carry, Overflow) fornecem informações sobre o resultado, permitindo que a CPU tome decisões. Cada vez que você faz uma conta, compara dois valores ou toma uma decisão no computador, é a ULA que está trabalhando. Sem ela, o computador seria apenas um grande armazenador de dados, incapaz de processar qualquer informação."**

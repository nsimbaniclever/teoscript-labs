# Memória RAM

## 1. Introdução

Nas duas últimas aulas, exploramos os níveis mais rápidos e caros da hierarquia de memória: os **Registradores**, que ficam dentro da CPU e são acessados em 1 ciclo, e a **Cache** (L1, L2, L3), que fica entre a CPU e a RAM e reduz o tempo de espera . Agora descemos para o nível seguinte — a **Memória RAM** (Random Access Memory). Se os registradores são a mesa de trabalho do artesão e a cache é a gaveta de ferramentas, a RAM é a **estante de ferramentas** — o armazém principal onde todos os programas e dados em execução são mantidos.<br><br>

A RAM é onde:

- O sistema operacional reside enquanto o computador está ligado.
- Os programas são carregados para serem executados.
- Os dados abertos (documentos, imagens, vídeos) são armazenados temporariamente.

Diferente dos registradores e da cache, que são feitos com SRAM (estática, rápida, cara), a RAM é feita com **DRAM** (dinâmica, mais lenta, barata). Ela é a memória que você vê quando verifica o "Memória" no Gerenciador de Tarefas do Windows (8 GB, 16 GB, 32 GB).

Nesta aula, vamos explorar a Memória RAM: como ela funciona, os diferentes tipos (DDR4, DDR5), sua velocidade, capacidade e por que ela é essencial para o funcionamento do computador.


## 2. O Que é a Memória RAM?

### 2.1 Definição

A **RAM** (Random Access Memory) é a memória principal do computador, onde:

> **Programas e dados em execução são armazenados temporariamente para acesso rápido pela CPU.**

### 2.2 Características

| Característica | Valor Típico |
|----------------|--------------|
| **Tecnologia** | DRAM (Dynamic RAM) |
| **Capacidade** | 4 GB a 128 GB (comum: 8 GB, 16 GB, 32 GB) |
| **Velocidade** | ~50-100 ns (nanossegundos) |
| **Frequência** | 1600 MHz a 8400 MHz (DDR4/DDR5) |
| **Volatilidade** | Volátil (perde dados sem energia) |
| **Custo** | Barato (comparado com SRAM) |
| **Localização** | Na placa-mãe (slots DIMM) |

## 3. Tecnologia da RAM: DRAM

### 3.1 O que é DRAM?

**DRAM** (Dynamic RAM) é o tipo de memória usado na RAM principal. Ela usa **capacitores** para armazenar cada bit.

| Característica | Detalhe |
|----------------|---------|
| **Tecnologia** | 1 transistor + 1 capacitor por bit |
| **Velocidade** | Mais lenta que SRAM (~50-100 ns) |
| **Densidade** | Alta (muitos bits por área) |
| **Custo** | Barato (por bit) |
| **Refrescamento** | Precisa (a cada ~64 ms) |

### 3.2 Por que a DRAM precisa de refresh?

O capacitor na DRAM **perde carga** com o tempo devido a correntes de fuga. Sem refresh, o dado seria perdido em milissegundos.

- **Refresh:** A cada ~64 ms, todas as linhas da DRAM são lidas e reescritas.
- **Durante o refresh:** A memória não pode ser acessada (pequena penalidade de desempenho).

### 3.3 SRAM vs DRAM (Revisão)

| Característica | SRAM (Cache) | DRAM (RAM) |
|----------------|--------------|------------|
| **Tecnologia** | Flip-flop (6 transistores) | Capacitor (1T + 1C) |
| **Velocidade** | Muito rápida | Mais lenta |
| **Densidade** | Baixa | Alta |
| **Custo** | Caro | Barato |
| **Refresh** | Não precisa | Precisa |
| **Uso** | Cache, registradores | RAM principal |


## 4. Tipos de RAM: DDR4, DDR5, etc.

### 4.1 Evolução da RAM

| Geração | Lançamento | Velocidade (MT/s) | Tensão | Capacidade máxima |
|---------|------------|-------------------|--------|-------------------|
| **DDR** | 2000 | 200-400 | 2.5V | 1 GB |
| **DDR2** | 2003 | 400-1066 | 1.8V | 4 GB |
| **DDR3** | 2007 | 800-2133 | 1.5V | 16 GB |
| **DDR4** | 2014 | 1600-3200 | 1.2V | 128 GB |
| **DDR5** | 2020 | 4800-8400 | 1.1V | 512 GB+ |

### 4.2 DDR vs DDR4 vs DDR5

| Característica | DDR4 | DDR5 |
|----------------|------|------|
| **Velocidade** | 1600-3200 MT/s | 4800-8400 MT/s |
| **Tensão** | 1.2V | 1.1V |
| **Capacidade por pente** | 4-32 GB | 8-128 GB |
| **Largura de banda** | ~25.6 GB/s | ~51.2 GB/s |
| **Consumo** | Maior | Menor |

### 4.3 O que significa DDR?

**DDR** = **Double Data Rate** (Taxa de Dados Dupla).

- DDR transfere dados **duas vezes por ciclo de clock** (na subida e na descida).
- Uma memória DDR4-3200 tem clock de 1600 MHz, mas transfere a 3200 MT/s.


## 5. Capacidade e Desempenho

### 5.1 Quanta RAM é necessária?

| Uso | Capacidade sugerida |
|-----|---------------------|
| **Básico** (navegação, e-mail, documentos) | 4-8 GB |
| **Intermediário** (jogos leves, edição simples) | 8-16 GB |
| **Avançado** (jogos pesados, edição de vídeo) | 16-32 GB |
| **Profissional** (3D, IA, máquinas virtuais) | 32-64 GB+ |

### 5.2 Como a RAM afeta o desempenho?

| Situação | Efeito |
|----------|--------|
| **RAM suficiente** | O sistema funciona rapidamente |
| **RAM insuficiente** | O sistema usa o SSD/HD como "memória virtual" → MUITO lento |
| **RAM mais rápida** | Melhor desempenho em jogos e aplicações pesadas |
| **RAM em dual-channel** | Maior largura de banda (2x mais rápida) |

### 5.3 Memória Virtual (Swap)

Quando a RAM está cheia, o sistema operacional usa o SSD/HD como "memória virtual":

- **Swap (Linux)** / **Pagefile (Windows)**
- Muito mais lento que a RAM (µs/ms vs ns)
- Indica que você precisa de mais RAM!

> **"A memória RAM é o armazém principal do computador — onde programas e dados em execução são mantidos para acesso rápido pela CPU. Feita com tecnologia DRAM (capacitores), ela é mais lenta que a cache e os registradores, mas muito mais rápida que o armazenamento secundário (SSD/HD). A RAM é volátil — perde todos os dados quando o computador é desligado. As gerações evoluíram de DDR para DDR5, com velocidades cada vez maiores e consumo cada vez menor. A quantidade de RAM (8 GB, 16 GB, 32 GB) determina quantos programas podem rodar simultaneamente. Quando a RAM está cheia, o sistema usa memória virtual (swap), o que torna o computador extremamente lento. A RAM é o coração da memória volátil — sem ela, nenhum programa poderia ser executado."**

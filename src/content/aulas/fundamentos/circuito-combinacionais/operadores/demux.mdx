# Demultiplexador (DEMUX)

## 1. Introdução

Na aula anterior, aprendemos sobre o **Multiplexador (MUX)** — um circuito que seleciona uma entre várias entradas e a direciona para uma única saída. Agora, vamos estudar o seu **inverso**: o **Demultiplexador (DEMUX)**.<br><br>

Enquanto o MUX pega várias entradas e produz uma saída, o DEMUX faz o oposto: **pega uma única entrada e a direciona para uma das várias saídas**, baseado em bits de seleção.

**Analogia:** Pense no DEMUX como um **distribuidor de água** com uma torneira de entrada e vários canos de saída. Você pode abrir a torneira e direcionar a água para um cano específico, girando um seletor.

O demultiplexador é usado em diversas aplicações importantes:

- **Decodificadores de endereço** em memórias RAM
- **Distribuição de dados** para múltiplos dispositivos
- **Roteamento em sistemas de comunicação**
- **Controle de displays** e periféricos
- **Barramentos de dados** compartilhados

Nesta aula, vamos aprender como os demultiplexadores funcionam, como construí-los a partir de portas lógicas, e como eles se relacionam com os multiplexadores.


## 2. O Que é um Demultiplexador?

### 2.1 Definição

Um **Demultiplexador** (abreviado como **DEMUX**) é um circuito combinacional que:

> **Direciona uma única entrada para uma entre 2ⁿ saídas, baseado em n bits de seleção.**

### 2.2 Analogia

Pense no DEMUX como uma **caixa de correio** inteligente:

- Você tem uma entrada (a correspondência que chega).
- Você tem várias saídas (as caixas de correio de cada morador).
- Você usa um código (bits de seleção) para decidir em qual caixa a correspondência será depositada.
- A correspondência sempre chega a **apenas uma** caixa por vez.

## 3. Demultiplexador 1→2 (1 entrada, 1 bit de seleção)

### 3.1 Definição

Um DEMUX 1→2 tem:

- **1 entrada:** F
- **2 saídas:** D₀ e D₁
- **1 bit de seleção:** S

### 3.2 Tabela verdade

| S | D₀ | D₁ |
|---|----|----|
| 0 | F  | 0  |
| 1 | 0  | F  |

### 3.3 Expressões lógicas

> **D₀ = ¬S ∧ F**  
> **D₁ = S ∧ F**

### 3.5 Exemplo prático

**Qual a saída para S = 1, F = 1?**

**Passo 1:** D₀ = ¬S ∧ F = 0 ∧ 1 = 0
**Passo 2:** D₁ = S ∧ F = 1 ∧ 1 = 1

**Resposta:** D₀ = 0, D₁ = 1 ✅


## 4. Demultiplexador 1→4 (1 entrada, 2 bits de seleção)

### 4.1 Definição

Um DEMUX 1→4 tem:

- **1 entrada:** F
- **4 saídas:** D₀, D₁, D₂, D₃
- **2 bits de seleção:** S₁, S₀

### 4.2 Tabela verdade

| S₁ | S₀ | D₀ | D₁ | D₂ | D₃ |
|----|----|----|----|----|----|
| 0 | 0 | F | 0 | 0 | 0 |
| 0 | 1 | 0 | F | 0 | 0 |
| 1 | 0 | 0 | 0 | F | 0 |
| 1 | 1 | 0 | 0 | 0 | F |

### 4.3 Expressões lógicas

> **D₀ = ¬S₁ ∧ ¬S₀ ∧ F**  
> **D₁ = ¬S₁ ∧ S₀ ∧ F**  
> **D₂ = S₁ ∧ ¬S₀ ∧ F**  
> **D₃ = S₁ ∧ S₀ ∧ F**

### 4.5 Exemplo prático

**Qual a saída para S₁ = 1, S₀ = 0, F = 1?**

**Passo 1:** S₁ = 1, S₀ = 0 → seleciona D₂
**Passo 2:** D₂ = S₁ ∧ ¬S₀ ∧ F = 1 ∧ 1 ∧ 1 = 1
**Passo 3:** D₀ = 0, D₁ = 0, D₃ = 0

**Resposta:** D₂ = 1 ✅

## 6. DEMUX Aplicado: Decodificador de Endereço

### 6.1 O que é um decodificador de endereço?

Um decodificador de endereço é um circuito que recebe um endereço (em binário) e ativa a linha de memória correspondente. Este é um uso prático e importante do DEMUX.

### 6.4 O DEMUX na memória

Em uma memória RAM, o DEMUX é usado para selecionar qual linha de memória será lida ou escrita:

1. A CPU envia um endereço (por exemplo, `10`).
2. O DEMUX ativa a linha correspondente (Linha 2).
3. Os dados são lidos/escritos nessa linha.


## 7. DEMUX vs MUX: Qual a Diferença?

| Característica | MUX (Multiplexador) | DEMUX (Demultiplexador) |
|----------------|---------------------|-------------------------|
| **Direção** | Múltiplas → Uma | Uma → Múltiplas |
| **Entradas** | 2ⁿ entradas | 1 entrada |
| **Saídas** | 1 saída | 2ⁿ saídas |
| **Seleção** | n bits | n bits |
| **Analogia** | Seletor de canais | Distribuidor |
| **Uso** | Selecionar dados | Distribuir dados |

> **"O demultiplexador é o inverso do multiplexador: ele pega uma única entrada e a direciona para uma das várias saídas baseado em bits de seleção. Um DEMUX 1→2 tem 1 entrada, 2 saídas e 1 bit de seleção (D₀ = ¬S·F, D₁ = S·F). Um DEMUX 1→4 tem 4 saídas e 2 bits de seleção. Os demultiplexadores são usados como decodificadores de endereço em memórias RAM, para distribuição de dados para múltiplos dispositivos, e em diversas aplicações de roteamento e controle. Juntos, MUX e DEMUX formam a base do roteamento e distribuição de dados em sistemas digitais."**

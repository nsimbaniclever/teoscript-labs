# Multiplexador (MUX)

## 1. Introdução

Nas duas aulas anteriores, aprendemos a construir circuitos que realizam operações aritméticas: somadores e subtratores. Vimos como a ULA (Unidade Lógica e Aritmética) usa esses circuitos para executar operações matemáticas, portanto existe um problema: 
- Como a ULA "escolhe" qual operação realizar? 
- Como ela decide se vai somar ou subtrair? 
- E como ela seleciona os dados corretos para enviar para o somador ou subtrator?

A resposta está no **Multiplexador** (ou **MUX**) — um circuito combinacional que **seleciona** uma entre várias entradas e a envia para a saída, baseado em um conjunto de bits de seleção.

O multiplexador é um dos circuitos mais importantes e onipresentes na computação. Ele é usado para:

- Selecionar operandos na ULA
- Rotear dados entre registradores
- Escolher a próxima instrução em um processador
- Selecionar canais em sistemas de comunicação
- Implementar memórias e bancos de registradores

Nesta aula, vamos aprender como os multiplexadores funcionam, como construí-los a partir de portas lógicas, e como eles são usados em sistemas computacionais.


## 2. O Que é um Multiplexador?

### 2.1 Definição

Um **Multiplexador** (abreviado como **MUX**) é um circuito combinacional que:

> **Seleciona uma entre 2ⁿ entradas e a direciona para uma única saída, baseado em n bits de seleção.**

### 2.2 Analogia

Pense no multiplexador como um **interruptor giratório** (como o seletor de canais de uma TV):

- Você tem várias entradas (canais de TV).
- Você gira o botão (bits de seleção) para escolher qual canal deseja assistir.
- A saída é o canal selecionado.

## 3. Multiplexador 2→1 (2 entradas, 1 bit de seleção)

### 3.1 O mais simples dos MUX

Um MUX 2→1 tem:

- **2 entradas:** D₀ e D₁
- **1 bit de seleção:** S
- **1 saída:** F

### 3.2 Tabela verdade

| S | F |
|---|----|
| 0 | D₀ |
| 1 | D₁ |

### 3.3 Expressão lógica

> **F = (¬S ∧ D₀) ∨ (S ∧ D₁)**

### 3.5 Exemplo prático

**Qual a saída para S = 1, D₀ = 0, D₁ = 1?**

**Passo 1:** F = (¬S ∧ D₀) ∨ (S ∧ D₁)
**Passo 2:** ¬S = 0
**Passo 3:** F = (0 ∧ 0) ∨ (1 ∧ 1) = 0 ∨ 1 = **1**

**Resposta:** F = 1 ✅


## 4. Multiplexador 4→1 (4 entradas, 2 bits de seleção)

### 4.1 Definição

Um MUX 4→1 tem:

- **4 entradas:** D₀, D₁, D₂, D₃
- **2 bits de seleção:** S₁, S₀
- **1 saída:** F

### 4.2 Tabela verdade

| S₁ | S₀ | F |
|----|----|---|
| 0 | 0 | D₀ |
| 0 | 1 | D₁ |
| 1 | 0 | D₂ |
| 1 | 1 | D₃ |

### 4.3 Expressão lógica

> **F = (¬S₁ ∧ ¬S₀ ∧ D₀) ∨ (¬S₁ ∧ S₀ ∧ D₁) ∨ (S₁ ∧ ¬S₀ ∧ D₂) ∨ (S₁ ∧ S₀ ∧ D₃)**

**Passo 2:** F = D₂ = 1

**Resposta:** F = 1 ✅


## 5. Multiplexador 8→1 (8 entradas, 3 bits de seleção)

### 5.1 Definição

Um MUX 8→1 tem:

- **8 entradas:** D₀ a D₇
- **3 bits de seleção:** S₂, S₁, S₀
- **1 saída:** F

## 6. O MUX na ULA (Unidade Lógica e Aritmética)

### 6.1 Como a ULA usa multiplexadores

A ULA precisa realizar várias operações: soma, subtração, AND, OR, XOR, etc. O multiplexador é usado para **selecionar qual operação** será executada.

### 6.2 Exemplo: ULA com 4 operações

| Opcode (S₁,S₀) | Operação |
|----------------|----------|
| 00 | Soma (A + B) |
| 01 | Subtração (A - B) |
| 10 | AND (A ∧ B) |
| 11 | OR (A ∨ B) |


## 7. Aplicações Reais dos Multiplexadores

| Aplicação | Como usa o MUX |
|-----------|----------------|
| **ULA da CPU** | Seleciona a operação aritmética/lógica |
| **Banco de registradores** | Seleciona qual registrador ler/escrever |
| **Cache de memória** | Seleciona a linha de cache |
| **Decodificação de instruções** | Seleciona a operação a executar |
| **Comunicação de dados** | Multiplexação de sinais em um único canal |
| **Roteamento de dados** | Switch em redes de computadores |
| **Áudio e vídeo** | Seleção de canais (mixer) |
| **Displays** | Seleção de segmentos em displays de 7 segmentos |

> **"O multiplexador é um circuito que seleciona uma entre várias entradas baseado em bits de seleção. Um MUX 2→1 tem 2 entradas e 1 bit de seleção (F = ¬S·D₀ + S·D₁). Um MUX 4→1 tem 4 entradas e 2 bits de seleção. Um MUX 8→1 tem 8 entradas e 3 bits de seleção. Os multiplexadores são onipresentes em computadores: na ULA para selecionar operações, em bancos de registradores para selecionar registradores, em roteamento de dados, e em inúmeras outras aplicações. Eles são a base do roteamento e da seleção de dados em circuitos digitais."**

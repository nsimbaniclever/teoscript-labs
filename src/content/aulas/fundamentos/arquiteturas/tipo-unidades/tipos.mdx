# TIPOS DE DADOS

## 1. INTRODUÇÃO

Na aula anterior, estudamos as unidades de medida — como medimos a quantidade de informação em bits, bytes e seus múltiplos. Vimos que um byte pode representar 256 valores diferentes, mas não especificamos **o que** esses valores significam.<br><br>

Um byte pode ser um número inteiro, uma letra, um valor lógico (verdadeiro/falso), ou parte de um número maior. A interpretação depende do **tipo de dado**. O tipo de dado define:

1. **Quantos bytes** são usados para armazenar o dado.
2. **Como os bits são interpretados** (ex: com ou sem sinal, inteiro ou ponto flutuante).
3. **Quais operações** podem ser realizadas com esse dado.<br><br>

Imagine que você está em uma loja de ferragens. Você vê uma caixa com vários objetos. Se a caixa estiver rotulada "Parafusos", você sabe que são parafusos — mesmo antes de abrir. Se estiver rotulada "Porcas", você sabe que são porcas. O rótulo (tipo de dado) diz ao computador como interpretar os bits (objetos) na memória.<br><br>

Nesta aula, vamos estudar os tipos de dados: os primitivos (int, float, bool, char) e os compostos (arrays, structs, classes). Vamos entender como eles são armazenados na memória, como são interpretados e como são usados em programação.

## 2. TIPOS DE DADOS PRIMITIVOS

### 2.1 Definição

> "Tipos de dados primitivos são os tipos fundamentais fornecidos por uma linguagem de programação, que representam valores simples e indivisíveis, como números inteiros, números de ponto flutuante, caracteres e valores booleanos."

### 2.2 Os principais tipos primitivos

| Tipo | Descrição | Tamanho típico | Exemplo |
|---------|---------|---------|---------|
| **int** | Número inteiro (com sinal) | 4 bytes (32 bits) | 42, -15, 0 |
| **unsigned int** | Número inteiro (sem sinal) | 4 bytes (32 bits) | 0, 42, 65535 |
| **float** | Número de ponto flutuante (precisão simples) | 4 bytes (32 bits) | 3.14, -2.5, 1.0e-3 |
| **double** | Número de ponto flutuante (precisão dupla) | 8 bytes (64 bits) | 3.1415926535, -2.5e-10 |
| **char** | Caractere (ASCII/Unicode) | 1 byte (8 bits) | 'A', '7', '\n' |
| **bool** | Valor lógico (verdadeiro/falso) | 1 byte (8 bits) | true, false |

### 2.3 int — Números inteiros

**Representação:** Complemento de 2 (com sinal) ou binário puro (sem sinal).

| Tamanho | Com sinal | Sem sinal |
|---------|---------|---------|
| **8 bits** | -128 a 127 | 0 a 255 |
| **16 bits** | -32.768 a 32.767 | 0 a 65.535 |
| **32 bits** | -2.147.483.648 a 2.147.483.647 | 0 a 4.294.967.295 |
| **64 bits** | -9.22e18 a 9.22e18 | 0 a 1.84e19 |

**Representação:** IEEE 754 (padrão internacional).

### 2.5 char — Caracteres

**Representação:** ASCII (7 bits) ou Unicode (16-32 bits).

| Tipo | Tamanho | Representação |
|---------|---------|---------|
| **char** | 1 byte | ASCII (0-127) |
| **wchar_t** | 2 bytes | Unicode (UCS-2) |
| **char32_t** | 4 bytes | Unicode (UTF-32) |

### 2.6 bool — Valores lógicos

**Representação:** 0 = false, 1 = true (ou qualquer valor diferente de 0).

| Valor | Representação em bits |
|---------|---------|
| **false** | 0 (0000 0000) |
| **true** | 1 (0000 0001) |

## 3. TIPOS DE DADOS COMPOSTOS

### 3.1 Definição

> "Tipos de dados compostos são tipos que agrupam múltiplos valores (primitivos ou outros compostos) em uma única estrutura, permitindo organizar dados complexos de forma coerente."

### 3.2 Array — Conjunto ordenado

**Definição:** Um array é uma coleção de elementos do **mesmo tipo**, armazenados em posições contíguas de memória.

**Estrutura:**

### 3.3 Struct — Conjunto heterogêneo

### 3.5 Class — Objeto com comportamento

**Definição:** Uma classe é uma estrutura que agrupa **dados (atributos)** e **comportamento (métodos)** , sendo a base da programação orientada a objetos.

**Exemplo em Python:**

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">

## 5. ALINHAMENTO E PADDING

### 5.1 O que é alinhamento?

Para eficiência, os processadores acessam memória em palavras (4 ou 8 bytes). Dados desalinhados podem causar penalidades de desempenho.

### 5.2 Exemplo: Struct com padding

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
struct Exemplo1 {
    char a;     // 1 byte
    int b;      // 4 bytes
    char c;     // 1 byte
};
</pre>

**Sem padding (suposto):** 1 + 4 + 1 = 6 bytes
**Com padding (real):** 12 bytes (padding de 3 bytes após a, 3 bytes após c)

**Por que?** O campo `int` precisa estar alinhado a 4 bytes.

### 5.3 Organização para minimizar padding

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
struct Exemplo2 {
    int b;      // 4 bytes
    char a;     // 1 byte
    char c;     // 1 byte
};              // 8 bytes (menos padding!)
</pre>

**Regra:** Colocar campos maiores primeiro para minimizar padding.

- Valor armazenado: 234 (inteiro)

**Cálculo:** -50°C a 50°C com 0.1°C de precisão → 1000 valores possíveis → 10 bits são suficientes (1024 valores). `short` (16 bits) é mais que suficiente.

**Conclusão:** Usar `short` e armazenar o valor multiplicado por 10.

> Tipos de dados são a gramática da memória — eles definem como os bits são interpretados e como os dados são organizados. Primitivos como int, float, bool e char são os blocos fundamentais. Compostos como arrays, structs, unions e classes são as estruturas que organizam esses blocos em padrões complexos, refletindo a complexidade do mundo real. Entender os tipos de dados é essencial para qualquer programador. Eles determinam como a memória é usada, como os dados são interpretados e quais operações são possíveis. Escolher o tipo certo para cada situação é uma arte que combina conhecimento de hardware, requisitos de aplicação e boas práticas de programação.

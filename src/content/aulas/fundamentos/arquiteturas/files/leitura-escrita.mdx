# LEITURA E ESCRITA DE ARQUIVOS

## 1. INTRODUÇÃO

Nas últimas doze aulas, estudamos como os computadores processam dados: desde a execução de instruções no pipeline até a organização da memória e a estruturação de dados em tipos. Mas há uma pergunta fundamental que ainda não respondemos: **como os dados são salvos de forma persistente?**<br><br>

Quando você desliga o computador, os dados na RAM são perdidos. Para guardar informações permanentemente, precisamos de **arquivos** — estruturas de dados armazenadas em dispositivos de armazenamento (HD, SSD, etc.). Os arquivos são a base da persistência digital: documentos, fotos, vídeos, programas, configurações, bancos de dados — todos são arquivos.<br><br>

A leitura e escrita de arquivos é uma habilidade essencial para qualquer programador. É assim que os programas interagem com o sistema de arquivos, lendo configurações, processando dados de entrada e salvando resultados.<br><br>

Imagine que você está escrevendo um livro. A RAM é a sua mente — onde você organiza as ideias enquanto escreve. O arquivo é o papel onde você escreve o livro para que ele não seja perdido quando você parar de pensar. A leitura e escrita de arquivos são o ato de transferir ideias da mente para o papel (e vice-versa).<br><br>

Nesta aula, vamos estudar a leitura e escrita de arquivos: como abrir, ler, escrever e fechar arquivos, quais são os modos de acesso, e como diferentes tipos de arquivos são manipulados.

## 2. O QUE É UM ARQUIVO?

### 2.1 Definição

> "Um arquivo é uma coleção nomeada de dados armazenados em um dispositivo de armazenamento persistente (HD, SSD, etc.), que pode ser lido, escrito e gerenciado pelo sistema operacional."

### 2.2 Características principais

| Característica | Descrição |
|---------|----------|
| **Persistência** | Os dados permanecem após o programa terminar |
| **Nome** | Identificador único no sistema de arquivos |
| **Tamanho** | Quantidade de bytes que ocupa |
| **Tipo** | Binário, texto, executável, etc. |
| **Permissões** | Quem pode ler, escrever, executar |
| **Metadados** | Data de criação, modificação, etc. |

### 2.3 Analogia

Um arquivo é como uma **página em um caderno**. Você pode escrever nela (escrever), ler o que escreveu (ler), rasgar a página e começar de novo (sobrescrever), ou guardar o caderno na estante para ler depois (persistência).

### 3.2 Modos de abertura de arquivo

| Modo | Descrição | Ação |
|---------|---------|---------|
| **r** | Leitura (read) | Abre o arquivo para leitura. Erro se não existir. |
| **w** | Escrita (write) | Abre para escrita. Cria se não existir. Sobrescreve se existir. |
| **a** | Append (anexar) | Abre para escrita no final do arquivo. Cria se não existir. |
| **r+** | Leitura e escrita | Abre para leitura e escrita. Erro se não existir. |
| **w+** | Leitura e escrita | Abre para leitura e escrita. Cria/sobrescreve. |
| **a+** | Leitura e append | Abre para leitura e escrita no final. Cria se não existir. |
| **rb** | Leitura binária | Abre arquivo binário para leitura. |
| **wb** | Escrita binária | Abre arquivo binário para escrita. |

    <pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">

            arquivo.write("Linha 2: Esta é a segunda linha.\n")

        print("Arquivo 'exemplo.txt' criado com 3 linhas.")

        // 2. LER UM ARQUIVO INTEIRO
        print("\n📌 LENDO O ARQUIVO INTEIRO")
        with open("exemplo.txt", "r") as arquivo:
            conteudo = arquivo.read()
            print(f"Conteúdo:\n{conteudo}")

        // 3. LER LINHA POR LINHA
        print("\n📌 LENDO LINHA POR LINHA")
        with open("exemplo.txt", "r") as arquivo:
            for linha in arquivo:
                print(f"Linha: {linha.strip()}")

        // 4. ADICIONAR AO FINAL DO ARQUIVO (APPEND)
        print("\n📌 ADICIONANDO AO FINAL DO ARQUIVO")
        with open("exemplo.txt", "a") as arquivo:
            arquivo.write("Linha 4: Esta linha foi adicionada no final.\n")
        print("Linha adicionada ao final do arquivo.")

        // 5. LER ARQUIVO BINÁRIO
        print("\n📌 LENDO ARQUIVO BINÁRIO")
        with open("imagem.jpg", "rb") as arquivo:
            dados = arquivo.read(100)  # Lê os primeiros 100 bytes
            print(f"Primeiros 100 bytes: {dados[:20]}...")

### 4.2 Movendo o ponteiro — Seek

A função `seek` move o ponteiro de posição para uma localização específica.

| Origem | Descrição |
|---------|----------|
| **SEEK_SET** | Início do arquivo |
| **SEEK_CUR** | Posição atual |
| **SEEK_END** | Final do arquivo |

**Exemplo (Python):**

<details>
<summary> Exemplo (Python)</summary>
    <pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
# Abrir arquivo
with open("dados.bin", "rb") as f:
    Ir para o byte 100
    f.seek(100, 0)  # SEEK_SET = 0
    
    Ler 10 bytes a partir da posição 100
    dados = f.read(10)
    
    Voltar 5 bytes da posição atual
    f.seek(-5, 1)   # SEEK_CUR = 1
    
    Ir para o final do arquivo
    f.seek(0, 2)    # SEEK_END = 2
</pre>

## 6. GERENCIAMENTO DE ARQUIVOS EM PROGRAMAÇÃO

### 6.1 Boas práticas

| Prática | Descrição |
|---------|----------|
| **Sempre fechar arquivos** | Libera recursos do sistema |
| **Usar context managers** | `with open(...) as f:` em Python (fecha automaticamente) |
| **Tratar exceções** | Arquivo pode não existir, sem permissão, etc. |
| **Verificar retorno** | Em C, verifique se `fopen` retornou NULL |
| **Flush** | Garantir que dados sejam escritos fisicamente |

### 6.2 Exemplo com tratamento de exceções

<details>
<summary> Exemplo com tratamento de exceções</summary>

    with open("dados.txt", "r") as arquivo:

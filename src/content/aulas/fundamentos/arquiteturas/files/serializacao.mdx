# SERIALIZAÇÃO DE OBJETOS — PICKLE

## 1. INTRODUÇÃO

Nas últimas quatro aulas, estudamos formatos de arquivo para dados: CSV (tabelas planas), JSON (dados hierárquicos para APIs) e XML (dados estruturados com validação). Cada um tem seu propósito, e todos são formatos de **texto** — legíveis por humanos e intercambiáveis entre sistemas.<br><br>

Mas há um problema: nem tudo pode ser facilmente convertido para texto. Objetos complexos com métodos, referências circulares e estados internos não se encaixam naturalmente em JSON ou XML. Além disso, a conversão para texto e de volta (serialização/desserialização) tem custo de desempenho.<br><br>

É aí que entra a **serialização binária**. Em vez de converter objetos para texto, a serialização binária converte objetos para uma **representação binária** (bytes) que pode ser salva em disco ou transmitida pela rede. O formato mais conhecido em Python para isso é o **Pickle**.<br><br>

Imagine que você está guardando um quebra-cabeça. Em vez de desmontar todas as peças e escrever um manual de como montá-lo (texto), você simplesmente guarda o quebra-cabeça inteiro em uma caixa (binário). Quando você abre a caixa, o quebra-cabeça está exatamente como você deixou. O Pickle faz isso com objetos Python.<br><br>

Nesta aula, vamos estudar a serialização de objetos com Pickle: o que é, como funciona, suas vantagens e desvantagens, e quando usar (e quando não usar).

## 2. O QUE É SERIALIZAÇÃO?

### 2.1 Definição

> "Serialização é o processo de converter uma estrutura de dados ou objeto em um formato que pode ser armazenado (em um arquivo) ou transmitido (pela rede) e posteriormente reconstruído (desserializado)."

### 2.3 Formatos de serialização

| Formato | Tipo | Vantagem | Desvantagem |
|---------|---------|---------|---------|

## 3. O QUE É PICKLE?

### 3.1 Definição

> "Pickle é o módulo de serialização nativo do Python que converte objetos Python em uma representação binária (bytes) e vice-versa, permitindo salvar e carregar objetos complexos de forma eficiente."

### 3.2 Características principais

| Característica | Descrição |
|---------|----------|
| **Formato** | Binário (não legível por humanos) |
| **O que suporta** | Praticamente todos os objetos Python |
| **Vantagem** | Suporta objetos complexos, eficiente |
| **Desvantagem** | Inseguro (pode executar código malicioso), não portável entre versões |

### 3.3 O que o Pickle suporta?

| Tipo | Suportado? | Exemplo |
|---------|---------|---------|
| **Primitivos** | ✅ | int, float, bool, str, bytes |
| **Coleções** | ✅ | list, tuple, dict, set |
| **Objetos** | ✅ | Instâncias de classes |
| **Funções** | ✅ | Funções (com restrições) |
| **Classes** | ✅ | Classes (com restrições) |
| **Referências circulares** | ✅ | Objetos que se referenciam |
| **Objetos com métodos** | ✅ | Instâncias com métodos |

### 4.3 Desserializando (carregando)

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
import pickle

# 1. Carregar um objeto simples
print("\n📌 CARREGANDO OBJETO SIMPLES")
with open("dados.pkl", "rb") as arquivo:  # 'rb' = read binary
    dados = pickle.load(arquivo)
print(f"Carregado: {dados}")

# 2. Carregar de bytes
print("\n📌 CARREGANDO DE BYTES")
dados_bytes = pickle.dumps({"nome": "João", "idade": 30})
dados = pickle.loads(dados_bytes)
print(f"Carregado: {dados}")

# 3. Carregar uma lista
print("\n📌 CARREGANDO LISTA")
with open("pessoas.pkl", "rb") as arquivo:
    pessoas = pickle.load(arquivo)
for pessoa in pessoas:
    print(f"Nome: {pessoa['nome']}, Idade: {pessoa['idade']}")

# 4. Carregar um objeto de classe
print("\n📌 CARREGANDO OBJETO DE CLASSE")
with open("pessoa_objeto.pkl", "rb") as arquivo:
    pessoa = pickle.load(arquivo)
print(f"Nome: {pessoa.nome}, Idade: {pessoa.idade}, Cidade: {pessoa.cidade}")
print(f"Saudação: {pessoa.saudacao()}")
</pre>

### 4.4 Múltiplos objetos no mesmo arquivo

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
import pickle

# Salvando múltiplos objetos
with open("multiplos.pkl", "wb") as arquivo:
    pickle.dump({"nome": "Ana"}, arquivo)
    pickle.dump({"nome": "João"}, arquivo)
    pickle.dump({"nome": "Maria"}, arquivo)

# Carregando múltiplos objetos
with open("multiplos.pkl", "rb") as arquivo:
    try:
        while True:
            obj = pickle.load(arquivo)
            print(f"Carregado: {obj}")
    except EOFError:
        print("Fim do arquivo!")
</pre>

## 6. SEGURANÇA NO PICKLE

### 6.1 O perigo do Pickle

Pickle é **inseguro** para dados de fontes não confiáveis. Um arquivo pickle malicioso pode executar código arbitrário.

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
# EXEMPLO DE ARQUIVO MALICIOSO (não execute!)
import pickle
import os

# Um arquivo pickle pode executar código quando carregado
class Malicioso:
    def __reduce__(self):
        return (os.system, ("rm -rf /",))  # NUNCA FAÇA ISSO!

dados = pickle.dumps(Malicioso())
pickle.loads(dados)  # ⚠️ Isso deletaria todos os seus arquivos!
</pre>

### 6.2 Boas práticas

| Prática | Descrição |
|---------|----------|
| **Nunca usar pickle com dados externos** | Sempre use para dados confiáveis apenas |
| **Validar antes de carregar** | Verifique a integridade se possível |
| **Usar `pickle` com `restricted`** | Python tem opções restritas (mas não são perfeitas) |
| **Alternativas seguras** | JSON, MessagePack, Protocol Buffers |

### 6.3 Alternativas seguras ao Pickle

| Alternativa | Descrição |
|---------|----------|
| **JSON** | Formato de texto, seguro, universal |
| **MessagePack** | Binário, mais compacto que JSON, seguro |
| **Protocol Buffers** | Binário, rápido, tipado, seguro |
| **YAML** | Texto, legível, seguro |

with open("alunos.pkl", "rb") as arquivo:
    alunos_carregados = pickle.load(arquivo)

> Pickle é a serialização nativa do Python — rápida, completa e eficiente. Ela preserva objetos complexos, referências circulares e estruturas de dados aninhadas. Mas é insegura para dados externos e não é interoperável com outras linguagens. Use-a para salvar o estado do seu programa, não para transmitir dados pela internet. O Pickle é uma ferramenta poderosa dentro do ecossistema Python. Sua capacidade de serializar praticamente qualquer objeto Python — incluindo classes personalizadas, funções e estruturas complexas — o torna ideal para caching, checkpoints e persistência de modelos de machine learning. No entanto, sua natureza binária e insegura exige cuidado: use apenas com dados confiáveis e considere alternativas como JSON ou MessagePack para dados que precisam ser compartilhados entre diferentes sistemas ou linguagens.

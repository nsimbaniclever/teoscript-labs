# FORMATO JSON

## 1. INTRODUÇÃO

Nas últimas duas aulas, estudamos arquivos de texto e o formato CSV. Vimos que o CSV é excelente para dados tabulares simples — tabelas com linhas e colunas. Mas há uma limitação: o CSV não suporta estruturas hierárquicas ou aninhadas.<br><br>

E quando precisamos representar dados mais complexos? Dados com objetos aninhados, listas dentro de objetos, ou estruturas que não cabem em uma tabela plana? É aí que entra o **JSON (JavaScript Object Notation)**.<br><br>

JSON é o formato de dados da internet moderna. Quando você usa um aplicativo de celular, está trocando dados JSON com servidores. Quando você chama uma API (Application Programming Interface), a resposta vem em JSON. Quando você configura serviços em nuvem, usa JSON.<br><br>

Imagine que o CSV é uma tabela de dados em uma planilha. O JSON é um **documento com capítulos, seções, parágrafos e notas de rodapé** — uma estrutura hierárquica que pode representar dados complexos de forma natural.<br><br>

Nesta aula, vamos estudar o JSON: sua estrutura, tipos de dados suportados, como ler e escrever em várias linguagens, e por que ele se tornou o padrão para APIs e comunicação entre sistemas.

## 2. O QUE É JSON?

### 2.1 Definição

> "JSON (JavaScript Object Notation) é um formato leve de intercâmbio de dados, baseado em texto, que utiliza uma sintaxe legível por humanos para representar estruturas de dados compostas por pares chave-valor e listas ordenadas."

### 2.2 Características principais

| Característica | Descrição |
|---------|----------|
| **Formato** | Texto simples (UTF-8) |
| **Estrutura** | Objetos (chave-valor) e arrays (listas ordenadas) |
| **Tipos suportados** | String, Number, Boolean, Null, Object, Array |
| **Vantagens** | Legível, leve, suportado por todas as linguagens |
| **Uso principal** | APIs, configurações, troca de dados entre sistemas |

### 2.3 Analogia

JSON é como um **formulário de cadastro**:

- **Objeto:** O formulário inteiro (um "documento").
- **Chave:** O nome de cada campo (ex: "nome", "idade", "cidade").
- **Valor:** O preenchimento de cada campo (ex: "João", 30, "São Paulo").
- **Array:** Uma lista de itens (ex: lista de telefones).

## 3. ESTRUTURA DO JSON

### 3.1 Tipos de dados JSON

| Tipo | Descrição | Exemplo |
|---------|---------|---------|
| **String** | Texto entre aspas duplas | `"João Silva"` |

### 3.4 Regras de sintaxe JSON

| Regra | Descrição | Correto | Incorreto |
|---------|---------|---------|---------|
| **Aspas duplas** | Chaves e strings usam aspas duplas | `{"nome": "João"}` | `{'nome': 'João'}` |
| **Vírgulas** | Separar elementos | `{"a":1, "b":2}` | `{"a":1 "b":2}` |
| **Último elemento** | Sem vírgula no final | `[1, 2, 3]` | `[1, 2, 3,]` |
| **Objetos** | Entre chaves `{}` | `{"nome": "João"}` | `("nome": "João")` |
| **Arrays** | Entre colchetes `[]` | `[1, 2, 3]` | `(1, 2, 3)` |

## 4. JSON VS CSV — COMPARAÇÃO

| Característica | CSV | JSON |
|---------|---------|---------|
| **Estrutura** | Tabela plana | Hierárquica (aninhada) |
| **Tipos de dados** | Todos texto (tudo é string) | Tipos nativos (string, number, bool, null) |
| **Hierarquia** | Não suporta | Suporta objetos aninhados |
| **Listas** | Colunas separadas | Arrays nativos |
| **Legibilidade** | Excelente para tabelas | Excelente para estruturas complexas |
| **Tamanho** | Compacto | Maior (mais caracteres) |
| **Uso** | Dados tabulares, planilhas | APIs, configurações, dados complexos |

## 5. LENDO E ESCREVENDO JSON EM PYTHON

### 5.1 O módulo `json`

Python tem um módulo embutido para trabalhar com JSON: o `json`.

### 5.2 Lendo um arquivo JSON

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
import json

# Lendo arquivo JSON
print("\n📌 LENDO ARQUIVO JSON")
with open("pessoa.json", "r", encoding="utf-8") as arquivo:
    dados = json.load(arquivo)
    print(f"Nome: {dados['nome']}")
    print(f"Idade: {dados['idade']}")
    print(f"Telefones: {dados['telefones']}")
    print(f"Endereço: {dados['endereco']['rua']}")

# Lendo string JSON (ex: resposta de API)
print("\n📌 LENDO STRING JSON")
json_string = '{"nome": "João", "idade": 30}'
dados = json.loads(json_string)
print(f"Nome: {dados['nome']}")
</pre>

### 5.3 Escrevendo um arquivo JSON

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
import json

# Dados para escrever
dados = {
    "nome": "Ana Souza",
    "idade": 28,
    "cidade": "São Paulo",
    "ativo": True,
    "salario": 4500.50,
    "telefones": ["(11) 99999-9999", "(11) 88888-8888"],
    "endereco": {
        "rua": "Rua das Flores",
        "numero": 123,
        "bairro": "Centro",
        "cep": "01000-000"
    }
}

# Escrevendo JSON formatado
print("\n📌 ESCREVENDO JSON FORMATADO")
with open("saida.json", "w", encoding="utf-8") as arquivo:
    json.dump(dados, arquivo, indent=2, ensure_ascii=False)
print("Arquivo JSON criado!")

# Escrevendo JSON compacto (minificado)
with open("saida_min.json", "w", encoding="utf-8") as arquivo:
    json.dump(dados, arquivo, separators=(",", ":"))
print("Arquivo JSON minificado criado!")

# Convertendo para string JSON
json_string = json.dumps(dados, indent=2, ensure_ascii=False)
print(f"\nJSON como string:\n{json_string}")
</pre>

### 5.4 Parâmetros importantes do `json.dump`

| Parâmetro | Descrição | Exemplo |
|---------|---------|---------|
| `indent` | Identação para legibilidade | `indent=2` |
| `ensure_ascii` | Mantém caracteres não-ASCII | `ensure_ascii=False` |
| `sort_keys` | Ordena as chaves | `sort_keys=True` |
| `separators` | Separadores compactos | `separators=(",", ":")` |

    "nome": "Ana Souza",

## 8. APLICAÇÕES REAIS

| Aplicação | Como usa JSON |
|---------|----------|
| **APIs REST** | Formato padrão para requisições e respostas |
| **Configurações** | Arquivos de configuração (ex: package.json) |
| **Bancos de dados NoSQL** | MongoDB, CouchDB usam JSON/BSON |
| **Web applications** | Comunicação frontend-backend (AJAX) |
| **Mobile apps** | Comunicação com servidores (iOS, Android) |
| **Ferramentas de CI/CD** | Configurações (ex: GitHub Actions) |
| **Analytics** | Coleta e envio de dados de eventos |

**Exemplo prático:** Quando você usa o aplicativo do Uber, ele envia sua localização em JSON para o servidor, e o servidor retorna os motoristas próximos em JSON.

<pre style="color: white; background: #0a0f1e; padding: 0.5rem; border-radius: 6px; font-family: monospace; font-size: 0.8rem; border: 1px solid rgba(255,255,255,0.05); overflow-x: auto;">

    json.dump(resultados, arquivo, indent=2, ensure_ascii=False)

Objetos e arrays, strings e números, booleanos e null — com esses blocos simples, o JSON constrói estruturas complexas que viajam entre servidores e clientes, alimentando APIs, aplicativos móveis e sistemas web.

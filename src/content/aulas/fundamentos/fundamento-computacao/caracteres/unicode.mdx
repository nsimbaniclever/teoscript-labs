
# Tabela Unicode

## O Padrão Universal de Codificação de Caracteres

## 1. Introdução

Na aula anterior, vimos que o ASCII foi o primeiro padrão internacional de codificação de caracteres. Ele resolveu o problema da comunicação entre computadores americanos, mas tinha uma limitação grave: **apenas 128 caracteres**. Não tinha acentos, não tinha 'ç', não tinha outros idiomas, não tinha emojis.

O mundo, porém, não é composto apenas pelo inglês. Existem milhares de idiomas no mundo: 
- **português** com seus acentos, 
- **espanhol** com seu 'ñ', 
- **alemão** com seu 'ü', 
- **francês** com seu 'ç', 
- **chinês** com seus milhares de caracteres, 
- **árabe** com sua escrita cursiva, e muito mais.

Como criar um único padrão que suporte **todos os idiomas do mundo**, ao mesmo tempo 🤔? Essa foi a missão do **Unicode**.

Nesta aula, vamos estudar o **Unicode** — o padrão que unificou todos os caracteres do mundo em uma única tabela gigante. Vamos entender o que ele é, como funciona, o que ele suporta, e por que ele é o padrão usado hoje em praticamente todos os computadores, celulares e sistemas do mundo.


## 2. O Que é o Unicode?

**Unicode** é um padrão internacional criado em **1993** com um objetivo ambicioso:

> **"Dar a cada caractere de cada idioma do mundo um número único e universal."**

Em outras palavras, o Unicode é uma **tabela gigante** que mapeia cada caractere — de letras a emojis, de símbolos matemáticos a caracteres antigos — a um **código único** chamado **ponto de código**.

### 2.1 Características do Unicode

| Característica | Detalhe |
|----------------|---------|
| **Criado em** | 1993 |
| **Número de caracteres** | +143.000 (e crescendo) |
| **Versão atual** | Unicode 15.1 (2023) |
| **Suporte** | Todos os idiomas, emojis, símbolos matemáticos, caracteres antigos |
| **Compatível com ASCII** | Sim (os primeiros 128 caracteres são idênticos) |
| **Onde é usado** | Praticamente todos os sistemas modernos |

### 2.2 Como funciona o ponto de código?

Cada caractere no Unicode tem um **ponto de código** único, representado em hexadecimal com o prefixo `U+`.

**Exemplos:**
- 'A' → Ponto de código `U+0041` (igual ao ASCII: 65)
- 'a' → Ponto de código `U+0061` (igual ao ASCII: 97)
- 'ç' → Ponto de código `U+00E7` (231 em decimal)
- 'ã' → Ponto de código `U+00E3` (227 em decimal)
- '€' → Ponto de código `U+20AC` (símbolo do euro)
- '😊' → Ponto de código `U+1F60A` (emoji)

**Analogia:** Pense no ponto de código como o **RG** de cada caractere. Cada caractere tem um número único e imutável que o identifica em todo o mundo.

### 2.4 O que o Unicode NÃO é

É importante entender que:

- **Unicode NÃO é um formato de armazenamento.** É apenas uma tabela que atribui números aos caracteres.
- **Unicode NÃO define quantos bytes cada caractere ocupa.** Isso é definido pelos formatos de codificação (UTF-8, UTF-16, UTF-32 — que veremos na próxima aula).
- **Unicode NÃO é um programa ou software.** É um padrão mantido pelo Unicode Consortium.

**Analogia:** O Unicode é como um **catálogo universal** que lista todos os livros do mundo e dá a cada um um número ISBN único. O catálogo não diz como os livros são armazenados (em papel, digital, áudio) — apenas dá um número único para cada livro.


## 3. A Evolução do ASCII para o Unicode

### 3.1 O problema que o Unicode resolveu

| Padrão | Caracteres | Problema |
|--------|------------|----------|
| **ASCII** | 128 (7 bits) | Só inglês. Sem acentos, 'ç', outros idiomas, emojis |
| **ISO-8859-1** | 256 (8 bits) | Só Europa Ocidental. Sem chinês, árabe, emojis |
| **ISO-8859-2** | 256 (8 bits) | Só Europa Oriental. Sem chinês, árabe, emojis |
| **ISO-8859-3** | 256 (8 bits) | Só Malta, Turquia. Sem chinês, árabe, emojis |
| **ISO-8859-...** | 256 (8 bits) | Cada região tinha sua própria versão. Caos total! |

**O caos dos anos 1980 e 1990:**
- Um arquivo salvo em ISO-8859-1 (Europa Ocidental) em um computador francês.
- Quando aberto em um computador chinês com ISO-8859-3 (Malta), os caracteres apareciam como garrancho.
- Quando aberto em um computador russo, aparecia outro garrancho completamente diferente.
- **Resultado:** Ninguém conseguia ler nada. O caos era total.

### 3.2 A solução do Unicode

O Unicode resolveu o problema de uma vez por todas:

1. **Uma única tabela** para todos os idiomas do mundo.
2. **Cada caractere tem um número único** (ponto de código).
3. **Compatível com ASCII** (os primeiros 128 caracteres são idênticos).
4. **Universal** — funciona em qualquer computador, em qualquer país, em qualquer sistema.

**Analogia:** Imagine que cada país tivesse seu próprio sistema de placas de carro. Um carro francês teria placas que ninguém na China entenderia. Um carro chinês teria placas que ninguém no Brasil entenderia. O Unicode criou um sistema de placas **único e universal** que funciona em todos os países do mundo.

### 3.3 Exemplo prático: "Ação" em Unicode

| Caractere | ASCII | ISO-8859-1 | Unicode (Ponto de Código) |
|-----------|-------|------------|---------------------------|
| A | ✅ 65 | ✅ 65 | ✅ U+0041 |
| ç | ❌ Não existe | ✅ 231 | ✅ U+00E7 |
| ã | ❌ Não existe | ✅ 227 | ✅ U+00E3 |
| o | ✅ 111 | ✅ 111 | ✅ U+006F |

**Resultado:** O Unicode suporta "Ação" perfeitamente. O ASCII não suporta. O ISO-8859-1 suporta, mas não suporta chinês, árabe ou emojis. O Unicode suporta tudo.

## 5. Pontos de Código e Como Ler Eles

### 5.1 O que é um ponto de código?

Um **ponto de código** é o número único que o Unicode atribui a cada caractere. Ele é representado em **hexadecimal** com o prefixo `U+`.

**Exemplos:**
- 'A' = U+0041 (65 em decimal)
- 'a' = U+0061 (97 em decimal)
- 'ç' = U+00E7 (231 em decimal)
- 'ã' = U+00E3 (227 em decimal)
- '€' = U+20AC (8364 em decimal)
- '😊' = U+1F60A (128522 em decimal)

### 5.2 Como converter ponto de código para decimal?

**Regra geral:** O ponto de código está em hexadecimal. Converta para decimal usando a tabela de conversão hexadecimal → decimal.

**Exemplo:** Converter U+00E7 para decimal.

**Passo 1:** Identifique o valor hexadecimal: `00E7`
**Passo 2:** Converta para decimal:
- `E` = 14 (em hexadecimal)
- `7` = 7 (em hexadecimal)
- `00E7` = (0 × 16³) + (0 × 16²) + (14 × 16¹) + (7 × 16⁰)
- `00E7` = 0 + 0 + 224 + 7 = 231

**Resposta:** U+00E7 = 231 em decimal (que é exatamente o valor ISO-8859-1 para 'ç'!)

**Exemplo:** Converter U+1F60A para decimal.

**Passo 1:** `1F60A`
**Passo 2:** Converta para decimal:
- `1F60A` = (1 × 16⁴) + (15 × 16³) + (6 × 16²) + (0 × 16¹) + (10 × 16⁰)
- `1F60A` = 65.536 + 61.440 + 1.536 + 0 + 10 = 128.522

**Resposta:** U+1F60A = 128.522 em decimal

### 5.3 Como o computador "entende" o ponto de código?

Quando você digita "😊" no teclado:
1. O sistema operacional consulta o Unicode.
2. O ponto de código é U+1F60A (128.522 em decimal).
3. O computador converte 128.522 para binário: `11111011000001010` (17 bits).
4. Esse binário é armazenado e transmitido.
5. Quando precisa mostrar na tela, o computador lê o binário, converte para o ponto de código, consulta a tabela Unicode e mostra o emoji "😊".

## 8. Por Que o Unicode Venceu

### 8.1 As razões do sucesso do Unicode

1. **Universalidade:** Suporta todos os idiomas do mundo — do português ao chinês, do árabe ao japonês.
2. **Compatibilidade com ASCII:** Os primeiros 128 caracteres são idênticos ao ASCII. Arquivos ASCII antigos continuam funcionando.
3. **Emojis:** O Unicode inclui emojis — algo essencial para a comunicação moderna.
4. **Expansibilidade:** O Unicode pode crescer. Novos caracteres são adicionados a cada versão.
5. **Padrão internacional:** Mantido pelo Unicode Consortium, com participação da Apple, Google, Microsoft, IBM, e outras grandes empresas.
6. **Gratuito:** Qualquer pessoa pode usar o Unicode sem pagar licenças.

### 8.2 O Unicode hoje

- **Versão atual:** Unicode 15.1 (2023)
- **+143.000 caracteres**
- **Suportado por:** Todos os sistemas operacionais modernos (Windows, macOS, Linux, iOS, Android)
- **Suportado por:** Todas as linguagens de programação modernas (Python, Java, JavaScript, C#, etc.)
- **Padrão da internet:** 99% dos sites usam Unicode (via UTF-8)

# DRAM — A MEMÓRIA DINÂMICA

## 1. INTRODUÇÃO

Na aula anterior, conhecemos a SRAM — a memória ultrarrápida usada como cache da CPU. Vimos que ela é extremamente rápida, mas também muito cara e com baixa capacidade. Um processador típico tem apenas alguns megabytes de SRAM, o que é suficiente para guardar os dados mais usados, mas não para armazenar programas inteiros.<br><br>

É aqui que entra a **DRAM (Dynamic RAM)**. A DRAM é a memória principal do computador — aquela que você compra em módulos para instalar no seu computador. Ela é mais lenta que a SRAM, mas muito mais barata e com muito maior capacidade. É nela que os programas em execução e os dados sendo processados ficam armazenados.<br><br>

A DRAM tem um nome curioso: "dinâmica". Diferente da SRAM (estática), a DRAM **precisa ser atualizada constantemente** para não perder os dados. É como se ela tivesse que "lembrar" os dados milhares de vezes por segundo, ou eles simplesmente desapareceriam.<br><br>

Nesta aula, vamos estudar a DRAM: o que ela é, como funciona, por que precisa de refresh, quais são suas vantagens e limitações, e como ela se compara à SRAM.

## 2. O QUE É A DRAM?

### 2.1 Definição

> "DRAM (Dynamic Random Access Memory) é um tipo de memória de acesso aleatório que armazena cada bit em um capacitor, necessitando de atualização (refresh) periódica para manter os dados, sendo mais lenta e barata que a SRAM."

### 2.2 Características principais

| Característica | Descrição |
|---------|----------|
| **Nome** | Dynamic RAM (Memória Dinâmica de Acesso Aleatório) |
| **Elemento de armazenamento** | Capacitor + 1 transistor (1T + 1C) |
| **Refresh** | Precisa (milhares de vezes por segundo) |
| **Velocidade** | Mais lenta (50-100 nanossegundos) |
| **Custo** | Barato (1 transistor + 1 capacitor por bit) |
| **Densidade** | Alta (muitos bits por chip) |
| **Consumo de energia** | Baixo (em comparação com SRAM) |
| **Onde é usada** | RAM principal do computador |

### 2.3 Analogia

A DRAM é como um **quadro de avisos** em uma escola. As informações são escritas com giz (capacitores), mas com o tempo, o giz se apaga. Alguém precisa passar o pano e reescrever tudo periodicamente (refresh) para que as informações não desapareçam. É trabalhoso, mas o quadro é grande, barato e pode conter muitas informações.

## 3. COMO A DRAM FUNCIONA?

### 3.1 O capacitor — o coração da DRAM

A DRAM armazena cada bit usando um **capacitor** e um **transistor**. O capacitor é um componente que armazena carga elétrica:

- **Capacitor carregado** = 1
- **Capacitor descarregado** = 0

**Como funciona:**

1. **Para escrever um bit (1):** O transistor é ativado, permitindo que a corrente carregue o capacitor.
2. **Para escrever um bit (0):** O transistor é ativado, permitindo que o capacitor descarregue.
3. **Para ler um bit:** O transistor é ativado, e o circuito mede a carga do capacitor.
4. **O problema:** Os capacitores perdem carga com o tempo (vazamento). É aí que entra o refresh.

### 3.2 O ciclo de refresh

Como os capacitores perdem carga naturalmente, a DRAM precisa ser **atualizada (refrescada)** milhares de vezes por segundo.

**Ciclo de refresh:**
1. O controlador de memória lê o valor de cada célula.
2. Reconhece o valor (0 ou 1).
3. Reescreve o valor na célula.
4. Repete para todas as células.

**Frequência:** Uma DRAM típica precisa de refresh a cada **64 milissegundos** (cerca de 15.625 vezes por segundo).

### 3.4 Por que a DRAM é mais lenta que a SRAM?

A DRAM é mais lenta por várias razões:

| Razão | Explicação |
|---------|----------|
| **Refresh** | Precisa parar para recarregar capacitores periodicamente |
| **Capacitores** | A carga/descarga dos capacitores é um processo físico que leva tempo |
| **Sinal fraco** | O sinal lido do capacitor é fraco e precisa ser amplificado |
| **Complexidade** | O circuito de refresh adiciona latência |

## 4. ONDE A DRAM É USADA?

### 4.1 A RAM principal

A DRAM é a **memória principal** de praticamente todos os computadores:

| Dispositivo | Quantidade típica de DRAM |
|---------|----------|
| **Computador de mesa** | 8-32 GB |
| **Notebook** | 8-16 GB |
| **Servidor** | 64-512 GB |
| **Celular** | 4-12 GB |
| **Tablet** | 4-8 GB |
| **Console de jogos** | 8-16 GB |

### 4.2 O que fica na DRAM?

Quando você liga o computador e abre um programa, o que acontece?

1. O programa está no HD/SSD (armazenamento permanente).
2. Quando você executa o programa, ele é **copiado para a DRAM**.
3. A CPU busca as instruções e dados da DRAM.
4. Quando você fecha o programa, ele pode permanecer na DRAM (cache de disco) ou ser removido.

**Exemplo:** Abrir um jogo de 50 GB no Steam:
- O jogo está no SSD (50 GB).
- Durante a execução, partes do jogo (texturas, modelos, código) são carregados na DRAM (8-16 GB).
- A CPU processa os dados da DRAM.
- Novas partes são carregadas conforme necessário.

### 4.3 A DRAM no dia a dia

Toda vez que você:
- Abre um programa
- Edita um documento
- Navega na internet
- Joga um jogo
- Assist a um vídeo

Você está usando a DRAM. Ela é o **espaço de trabalho** do computador.

## 5. DRAM VS SRAM — A COMPARAÇÃO DEFINITIVA

| Característica | SRAM | DRAM |
|---------|---------|---------|
| **Elemento** | Flip-flop (6 transistores) | Capacitor (1T + 1C) |
| **Refresh** | ❌ Não precisa | ✅ Precisa (milhares de vezes/segundo) |
| **Velocidade** | ⚡ Muito rápida (1-10 ns) | 🐢 Mais lenta (50-100 ns) |
| **Custo** | 💰💰💰 Muito caro | 💰 Barato |
| **Densidade** | Baixa (poucos bits) | Alta (muitos bits) |
| **Consumo** | Alto | Baixo |
| **Capacidade típica** | KB a MB | GB a TB |
| **Onde é usada** | Cache da CPU | RAM principal |

### 5.1 Por que a DRAM é tão mais barata?

A DRAM precisa apenas de **1 transistor e 1 capacitor** para armazenar cada bit. A SRAM precisa de **6 transistores**.

Isso significa que:
- Um chip de DRAM de 1 GB precisa de **1 bilhão de transistores e 1 bilhão de capacitores**.
- Um chip de SRAM de 1 GB precisaria de **6 bilhões de transistores**.

Menos transistores = menor área do chip = menor custo de fabricação.

### 5.2 O custo da DRAM vs SRAM

| Tipo | Custo por GB (aproximado) |
|---------|----------|
| **SRAM** | US$ 500-1.000 |
| **DRAM** | US$ 5-10 |
| **SSD** | US$ 0.10-0.50 |
| **HD** | US$ 0.02-0.05 |

**Observação:** A SRAM é cerca de **100 vezes mais cara** que a DRAM por gigabyte.

### 5.3 Exemplo: O que você pode comprar com US$ 100

| Tipo | Quantidade |
|---------|----------|
| **SRAM** | 100-200 MB |
| **DRAM** | 8-16 GB |
| **SSD** | 200-500 GB |
| **HD** | 2-4 TB |

## 6. O CICLO DE VIDA DA DRAM

### 6.1 Como os dados são armazenados

1. **Escrita:** O controlador ativa a linha de word, o transistor conduz, e o capacitor é carregado (1) ou descarregado (0).
2. **Leitura:** O controlador ativa a linha de word, o transistor conduz, e o circuito mede a carga do capacitor.
3. **Refresh:** O controlador lê e reescreve cada célula periodicamente.

### 6.2 Por que a DRAM é volátil?

A DRAM é volátil porque:
1. Os capacitores perdem carga com o tempo (vazamento).
2. Quando a energia é desligada, os capacitores descarregam completamente.
3. Não há mecanismo para manter os dados sem energia.

**Consequência:** Quando você desliga o computador, todos os dados na DRAM são perdidos. É por isso que você precisa salvar seus documentos no HD/SSD antes de desligar.

### 6.3 A DRAM e o consumo de energia

A DRAM consome energia principalmente durante:
1. **Leitura/escrita:** Acesso aos dados.
2. **Refresh:** Recarregar os capacitores.
3. **Standby:** Manter os capacitores carregados (consumo passivo).

Um módulo de DRAM típico (8 GB) consome cerca de **2-3 watts** em uso ativo.

## 7. APLICAÇÕES REAIS

| Aplicação | Como usa a DRAM |
|---------|----------|
| **Computadores pessoais** | Memória principal para executar programas |
| **Servidores web** | Cache de páginas, sessões de usuários |
| **Jogos** | Armazenar texturas, modelos, buffers de vídeo |
| **Edição de vídeo** | Armazenar frames, buffers de renderização |
| **Máquinas virtuais** | Cada VM precisa de sua própria DRAM alocada |
| **Celulares** | Apps em execução, multitarefa |
| **Data centers** | Hospedar milhares de servidores virtuais |

**Exemplo prático:** O Google tem data centers com **petabytes de DRAM** para processar bilhões de buscas por dia. Cada busca precisa acessar dados em milissegundos, e a DRAM é essencial para isso.

> A DRAM é o coração do espaço de trabalho do computador. Embora seja mais lenta que a SRAM e precise de refresh constante, sua combinação de baixo custo e alta capacidade a torna a escolha ideal para a memória principal. Sem a DRAM, não poderíamos executar programas complexos, jogos modernos ou sistemas operacionais completos. Ela é o palco onde toda a computação acontece — os programas são carregados nela, processados pela CPU, e salvos em armazenamento permanente quando terminamos.

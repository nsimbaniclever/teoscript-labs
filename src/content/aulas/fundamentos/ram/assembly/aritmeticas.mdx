# INSTRUÇÕES ARITMÉTICAS

## 1. INTRODUÇÃO

Nas aulas anteriores, estudamos a memória — onde os dados ficam armazenados. Vimos a hierarquia que vai dos registradores (mais rápidos) até a memória virtual (mais lenta). Mas a memória é apenas o palco. O que realmente importa é o que a CPU faz com os dados armazenados nela.<br><br>

A CPU (Unidade Central de Processamento) é o cérebro do computador. Sua função principal é **executar instruções**. E entre as instruções mais básicas e fundamentais estão as **instruções aritméticas** — operações matemáticas como soma, subtração, multiplicação e divisão.<br><br>

Imagine que a CPU é uma grande calculadora. Os números estão na memória (RAM), e a CPU os busca, realiza cálculos e coloca os resultados de volta na memória ou em registradores. Essas operações matemáticas são a base de tudo que um computador faz: desde somar 1+1 em uma planilha até calcular a física de um jogo ou renderizar um filme em 3D.<br><br>

Nesta aula, vamos estudar as instruções aritméticas em Assembly — a linguagem mais próxima do hardware. Vamos entender como a CPU soma, subtrai, multiplica e divide, e como essas operações são representadas no nível mais baixo da programação.

## 2. O QUE SÃO INSTRUÇÕES ARITMÉTICAS?

### 2.1 Definição

> "Instruções aritméticas são operações matemáticas básicas executadas pela CPU sobre dados armazenados em registradores ou na memória, incluindo soma, subtração, multiplicação, divisão e incremento/decremento."

### 2.2 Instruções aritméticas básicas

| Instrução | Operação | Exemplo | Significado |
|---------|---------|---------|---------|
| **ADD** | Soma (Addition) | `ADD R1, R2, R3` | R1 = R2 + R3 |
| **SUB** | Subtração (Subtraction) | `SUB R1, R2, R3` | R1 = R2 - R3 |
| **MUL** | Multiplicação (Multiplication) | `MUL R1, R2, R3` | R1 = R2 × R3 |
| **DIV** | Divisão (Division) | `DIV R1, R2, R3` | R1 = R2 ÷ R3 |
| **INC** | Incremento (Increment) | `INC R1` | R1 = R1 + 1 |
| **DEC** | Decremento (Decrement) | `DEC R1` | R1 = R1 - 1 |

### 2.3 Analogia

As instruções aritméticas são como as **operações básicas de uma calculadora**. Quando você aperta "+" em uma calculadora, ela soma dois números. A CPU faz a mesma coisa, mas com números binários e em velocidades de bilhões de operações por segundo.

## 3. COMO A CPU EXECUTA UMA INSTRUÇÃO ARITMÉTICA?

### 3.1 O ciclo de instrução (Fetch-Decode-Execute)

Toda instrução passa por três fases:

1. **Fetch (Busca):** A CPU busca a instrução na memória.
2. **Decode (Decodificação):** A CPU decodifica a instrução para entender o que fazer.
3. **Execute (Execução):** A CPU executa a instrução (ex: soma dois números).

## 4. INSTRUÇÕES ARITMÉTICAS EM ASSEMBLY

### 4.1 Sintaxe básica

A sintaxe geral de uma instrução aritmética em Assembly é:

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">

### 4.3 Variações de sintaxe (diferentes processadores)

Diferentes arquiteturas de processador têm sintaxes diferentes:

| Arquitetura | Soma | Subtração |
|---------|---------|---------|
| **ARM** | `ADD R1, R2, R3` | `SUB R1, R2, R3` |
| **x86 (Intel)** | `ADD EAX, EBX` | `SUB EAX, EBX` |
| **MIPS** | `add $t0, $t1, $t2` | `sub $t0, $t1, $t2` |

**Observação:** Em x86, o destino é o primeiro operando (ADD destino, fonte). Em ARM e MIPS, o destino é o primeiro registrador listado.

## 5. COMO A CPU LIDA COM NÚMEROS NEGATIVOS?

### 5.1 O problema dos números negativos

A CPU só entende binário (0s e 1s). Como representar números negativos?

**Solução:** Complemento de 2 (que vimos no módulo de sistemas numéricos).

### 5.2 Exemplo: Soma com números negativos

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
R2 = 10  (0000 1010)
R3 = -5  (1111 1011 em complemento de 2)

ADD R1, R2, R3
</pre>

A CPU soma 10 + (-5) = 5.

<pre style="color: white; background: #0a0f1e; padding: 1rem; border-radius: 8px; font-family: monospace; font-size: 0.85rem; border: 1px solid rgba(255,255,255,0.08); overflow-x: auto;">
  0000 1010  (10)
+ 1111 1011  (-5)
= 0000 0101  (5) ✅
</pre>

### 5.3 Flags (indicadores) da ALU

A ALU gera flags após cada operação:

| Flag | Descrição | Exemplo |
|---------|---------|---------|
| **Z (Zero)** | Resultado é zero | 5 - 5 = 0 → Z = 1 |
| **N (Negative)** | Resultado é negativo | 5 - 10 = -5 → N = 1 |
| **C (Carry)** | Houve "vai-um" (overflow) | 255 + 1 = 256 → C = 1 (em 8 bits) |
| **V (Overflow)** | Estouro de sinal | 127 + 1 = -128 (em 8 bits com sinal) |

Essas flags são usadas por instruções de desvio condicional (que veremos na próxima aula).

## 6. APLICAÇÕES REAIS

| Aplicação | Como usa instruções aritméticas |
|---------|----------|
| **Planilhas (Excel, Google Sheets)** | Somar, subtrair, multiplicar, dividir células |
| **Jogos** | Calcular física (velocidade, posição, colisão) |
| **Renderização 3D** | Transformações matemáticas (rotação, escala, translação) |
| **Compressão de dados** | Operações matemáticas para compactar arquivos |
| **Criptografia** | Operações aritméticas em números grandes |
| **Inteligência Artificial** | Multiplicação de matrizes (soma + multiplicação) |
| **Processamento de áudio/vídeo** | Operações matemáticas em amostras de áudio |

**Exemplo prático:** A cada frame de um jogo, a CPU executa milhões de instruções aritméticas para calcular posições de objetos, detectar colisões, aplicar física e renderizar gráficos.

> Instruções aritméticas são o coração matemático da CPU. ADD, SUB, MUL, DIV — com apenas essas operações básicas, a CPU pode executar qualquer cálculo, desde uma simples soma até a física de um jogo em 3D. A ALU (Unidade Lógica e Aritmética) é a responsável por executar essas operações em nanossegundos, bilhões de vezes por segundo. As instruções aritméticas são a base de toda a computação. Sem elas, não haveria planilhas, jogos, renderização 3D, criptografia ou inteligência artificial. Tudo o que um computador faz, em última análise, se resume a operações aritméticas e lógicas executadas em alta velocidade.
